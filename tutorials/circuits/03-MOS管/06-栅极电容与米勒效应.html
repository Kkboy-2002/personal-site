MOS管 · 栅极电容 · 米勒平台

栅极电容与米勒效应

MOS 管开关慢，不是沟道慢，而是栅极电容要充放电。其中 G-D 之间的电容 Cgd 会让 Vgs 在开通途中停下来一段，这就是米勒平台。下面调驱动电阻和 Cgd，看平台怎么变长变短。

三个极间电容

手册给的是 Ciss、Coss、Crss

物理上 MOS 管有三个极间电容：Cgs、Cgd、Cds。手册不直接给它们，给的是在某个 Vds 下测出的三个组合值。测输入电容时把 D-S 交流短路，从栅极看进去 Cgs 和 Cgd 并联；测输出电容时把 G-S 短路，从漏极看进去 Cds 和 Cgd 并联。

Ciss = Cgs + Cgd　　Coss = Cds + Cgd　　Crss = Cgd

这些电容都随 Vds 变化，尤其 Cgd，Vds 低时能比高压时大一个数量级，因为 G-D 之间的耗尽层随 Vds 变宽，相当于电容极板间距变大。

开通四个阶段 · 米勒平台

Vgs 为什么会停在一个平台上

以感性负载的低边开关为例，负载电流由续流二极管维持。驱动器经 Rg 给栅极充电，开通分四个阶段：

  1. Vgs 从 0 升到 Vth：给 Cgs 和 Cgd 充电，管子还没导通，Id = 0，Vds 保持母线电压。这段是开通延迟。
  2. Vgs 从 Vth 升到平台电压：Id 按转移特性上升到负载电流。续流二极管还没关断，Vds 仍被钳在母线电压。
  3. 米勒平台：Id 已满，Vgs 就锁定在对应这个电流的值 Vpl ≈ Vth + Id / gfs。Vds 开始下降，Cgd 两端电压跟着大幅变化，驱动电流全部用来给 Cgd 放电和反向充电，Vgs 不再上升。
  4. Vds 降到底后，驱动电流重新给 Cgs 和变大的 Cgd 充电，Vgs 升到驱动电压，Rds(on) 进一步降低。

米勒平台的长度 ≈ Qgd / Ig，Ig = (Vdrv − Vpl) / Rg。平台越长，Vds 和 Id 重叠的时间越长，开关损耗越大。之所以叫"米勒"，是因为 Cgd 跨在一个反相放大器的输入输出之间，从栅极看进去被放大成 (1 + gm·RL)·Cgd，和运放里的米勒电容是同一个道理。

米勒误导通 · 负压关断 · 米勒钳位

关着的管子被 Cgd "拽"开

半桥里下管关断时，上管一开通，下管漏极电压以很高的 dv/dt 上冲。这个电压变化经 Cgd 灌出一股电流 i = Cgd·dv/dt，流过下管的关断电阻到驱动器地，在栅极上抬出一个尖峰。尖峰超过 Vth，下管就被误开通，上下管直通。高温时 Vth 更低，更容易出事。

对策有四类：关断电阻取小，让这股电流有低阻通路；负压关断，给尖峰留出余量；米勒钳位，在 Vgs 已经很低时用一个小管子把栅极直接短到源极；降低 dv/dt 或在 G-S 并小电容分压，但会拖慢开关。

面试怎么答

常见追问

什么是米勒效应？米勒平台是怎么产生的？

Cgd 跨在栅极和漏极之间，而漏极电压和栅极电压反相变化，从栅极看进去 Cgd 被放大了 (1 + 增益) 倍，这就是米勒效应。开通时 Id 达到负载电流后，Vgs 被锁定在对应这个电流的平台电压上，驱动电流全部用来给 Cgd 充放电让 Vds 下降，Vgs 停住不动，形成平台。平台长度 ≈ Qgd / Ig。

Ciss、Coss、Crss 分别是什么？各影响什么？

Ciss = Cgs + Cgd，决定驱动要充多少电、开通延迟多长。Coss = Cds + Cgd，决定每次开关储存和损耗的能量 0.5·Coss·V^2，也决定软开关需要的换流能量。Crss = Cgd，决定米勒平台长度和抗 dv/dt 误导通的能力，越小越好。

栅极电阻取大还是取小？

是折中。Rg 小，平台短、开关损耗小，但 di/dt 和 dv/dt 大，振铃、EMI、电压尖峰都更严重。Rg 大则相反。常用做法是开通和关断分开：开通电阻稍大控制 EMI，关断用二极管旁路一个小电阻，关得快，也降低米勒误导通风险。

什么是米勒误导通？怎么解决？

半桥中一个管子开通时，另一个关断管的漏极电压快速上升，dv/dt 经 Cgd 注入电流，在关断电阻上产生压降抬高 Vgs，超过 Vth 就误开通，造成直通。解决办法：减小关断电阻；负压关断，比如 −3 ~ −5 V；加米勒钳位；G-S 并小电容；适当降低 dv/dt；选 Crss / Ciss 比值小、Vth 高的管子。
