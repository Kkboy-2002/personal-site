MOS管 · 跨导

跨导gm

栅压变一点，漏极电流变多少？这个比值就是跨导 gm，它衡量 MOS 管的"放大能力"。下面在转移曲线上拖动工作点，看切线斜率怎么变。

定义 · 转移曲线的斜率

gm 就是转移曲线在工作点的切线斜率

跨导的单位是西门子 S，也就是 A/V。输入是电压、输出是电流，所以叫"跨"导。对平方律 Id = K·(Vgs − Vth)^2 求导，就得到饱和区的 gm。

gm = ΔId / ΔVgs = 2·K·(Vgs − Vth) = 2·Id / (Vgs − Vth) = 2·√(K·Id)

三种写法是同一个东西。第一种说明 gm 随过驱动电压线性增大；第三种说明对同一颗管子，gm 只随 √Id 增长，电流翻四倍 gm 才翻一倍。

电压控制 · 共源放大

栅极只要电压，不要电流

栅极和沟道之间隔着一层绝缘的氧化层，直流下栅极电流只有 nA 级漏电。所以 MOS 管是电压控制器件：用 Vgs 控制 Id，不像三极管要靠基极电流 Ib 去控制 Ic。把 Id 的变化放到漏极电阻 Rd 上，就变成了电压放大，小信号增益为：

和三极管比

同样的电流，三极管的 gm 大得多

三极管的集电极电流和 Vbe 是指数关系，求导得 gm = Ic / VT，常温下 VT ≈ 26 mV。MOS 管是平方律，gm = 2·Id / (Vgs − Vth)。两式一比：

gm(BJT) / gm(MOS) = (Vgs − Vth) / (2·VT)

MOS 管的过驱动电压通常取 0.1~1 V，远大于 2·VT ≈ 52 mV，所以同电流下三极管的 gm 大几倍到十几倍。MOS 的优势在别处：输入阻抗极高、没有基极电流、开关快、好集成。

面试怎么答

常见追问

什么是跨导？MOS 管的 gm 怎么算？

跨导是输出电流变化量与输入电压变化量之比，gm = ΔId / ΔVgs，单位西门子，就是转移曲线在工作点的切线斜率。饱和区 gm = 2·K·(Vgs − Vth) = 2·Id / (Vgs − Vth)。

gm 和哪些因素有关？怎么提高？

gm = 2·√(K·Id)，K 正比于迁移率和宽长比 W/L。所以增大 W/L 或增大工作电流都能提高 gm，但对同一颗管子，gm 只随电流的平方根增长，代价是功耗上去得更快。

为什么说 MOS 管是电压控制器件，三极管是电流控制器件？

MOS 管栅极和沟道之间是绝缘层，直流下栅极几乎不取电流，Id 由 Vgs 决定。三极管要维持 Ic 必须持续提供基极电流 Ib ≈ Ic / β。不过 MOS 管开关时要给栅极电容充放电，动态驱动电流并不小。

同样电流下，三极管和 MOS 管谁的 gm 大？

三极管大。BJT 的 gm = Ic / VT，MOS 的 gm = 2·Id / (Vgs − Vth)，比值是 (Vgs − Vth) / (2·VT)。过驱动电压一般几百毫伏，远大于 52 mV，所以三极管 gm 大几倍到十几倍。MOS 只有在亚阈值区才接近三极管，但那时电流很小、速度很慢。

功率 MOS 手册里的 gfs 有什么用？

gfs 是正向跨导，就是大信号条件下的 gm。它能用来估算开关时的米勒平台电压：V(plateau) ≈ Vth + Id / gfs。负载电流越大，平台越高，驱动器剩下的充电电压越小，开关越慢。
