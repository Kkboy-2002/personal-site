MOS管 · 增强型与耗尽型

增强型与耗尽型

Vgs = 0 时管子是通还是断？这一点把 MOS 管分成增强型和耗尽型。下面拖动栅压，看沟道什么时候出现、什么时候消失。

有没有预置沟道

一个要"加压才通"，一个要"加压才断"

增强型 NMOS 出厂时源漏之间没有沟道，Vgs = 0 就关断，要加正压超过阈值 Vth 才能把沟道"吸"出来。耗尽型 NMOS 在制造时就在栅极下面注入了一层 N 型杂质，沟道天生就在，Vgs = 0 也导通；要加负压把沟道里的电子赶走、把沟道"耗尽"才能关断。关断所需的这个负电压叫夹断电压 Vgs(off)，本质上就是一个负的 Vth。

转移特性对比

两条曲线形状一样，只是左右平移

饱和区里两种管子都满足平方律 Id = K·(Vgs − Vth)^2。区别只在 Vth 的符号：增强型 NMOS 的 Vth 为正，曲线从右边起步；耗尽型 Vth 为负，曲线在 Vgs = 0 时已经有电流。耗尽型 Vgs = 0 时的电流叫 Idss，于是也常写成下面第二种形式。

Id = K·(Vgs − Vth)^2，Vgs > Vth
Id = Idss·(1 − Vgs / Vgs(off))^2，Idss = K·Vgs(off)^2

选型 · 为什么都用增强型

功率电路要的是"默认关断"

开关电源、电机驱动、电池保护这些电路里，驱动芯片没上电、MCU 复位、驱动线断了，栅极都会被下拉电阻拉到 0 V。增强型此时自然关断，电路处在安全状态；耗尽型此时反而全开，桥臂直通、负载失控。所以功率电路几乎全用增强型。

另一个原因是驱动简单：增强型 NMOS 只要 0 V 和 +10 V 两个电平，单电源就能驱动；耗尽型关断要负压，驱动得配负电源。

类型Vth 符号Vgs = 0 时符号沟道典型用途
N 沟道增强型正，约 +1~+4 V关断三段虚线低边开关、同步整流、半桥、几乎所有功率场合

耗尽型也有用武之地：栅源短接后 Vgs 恒为 0，漏极电流被钉在 Idss 附近，两个脚就构成一个简单的恒流源；离线开关电源刚上电时靠它从高压母线取电给控制芯片启动。另外，氮化镓 GaN HEMT 天生是耗尽型，功率应用里要用 p-GaN 栅结构或与硅管级联，把它做成增强型再用，也是出于"默认关断"的要求。

面试怎么答

常见追问

增强型和耗尽型 MOS 管有什么区别？

看 Vgs = 0 时有没有沟道。增强型没有沟道，Vgs = 0 关断，要加电压超过 Vth 才导通。耗尽型制造时预先做好了沟道，Vgs = 0 就导通，要加反向电压到夹断电压才关断。两者转移特性形状一样，都是平方律，只是 Vth 符号不同。

从符号上怎么区分？

看沟道那根竖线。增强型画成三段断开的虚线，表示平时没有沟道；耗尽型画成一条实线，表示沟道本来就在。

为什么功率电路几乎都用增强型？

一是失效安全：驱动掉电或栅极被下拉到 0 V 时，增强型自然关断，不会出现桥臂直通。二是驱动简单：单电源 0 V / 10 V 就能开关，耗尽型关断还要负电源。

耗尽型 MOS 管有什么实际用途？

栅源短接做两端恒流源；离线开关电源的高压启动电路；需要"默认导通"的常闭开关。GaN HEMT 天生是耗尽型，功率应用里通常做成 p-GaN 增强型或和硅 MOS 级联来用。
