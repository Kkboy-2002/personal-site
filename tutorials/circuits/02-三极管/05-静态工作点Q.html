三极管 · 直流偏置

静态工作点 Q

没有信号时管子的 Ib、Ic、Uce，叫静态工作点。交流信号是骑在它上面上下晃的，Q 点放在哪，决定了信号能晃多大而不被削掉。

为什么要偏置

交流信号必须骑在直流上

发射结有约 0.6 V 的导通门槛。不加偏置，输入信号的负半周和门槛以下的正半周都进不去，Ib 只剩几个尖顶，输出严重失真。先用直流把管子推到导通，再把交流叠上去，Ib 才能围绕一个直流值完整地上下变化。

固定偏置 · 三步算 Q

固定偏置电路怎么算 Q 点

最简单的偏置：一个大电阻 Rb 从 Vcc 接到基极。三步算完：

Ib = (Vcc − 0.7) / Rb　　Ic = β·Ib　　Uce = Vcc − Ic·Rc

算完别忘了验证 Uce 是否大于饱和压降，否则 Ic = β·Ib 不成立，见 三个工作区。

负载线 · 摆幅余量

Q 点放在负载线中点，摆幅最大

加上信号后，工作点沿负载线来回移动，输出 Uce 围绕 UceQ 上下摆。往上最多摆到 Vcc（管子截止，Ic = 0），往下最多摆到 Uces（管子饱和）。所以：

上余量 = Vcc − UceQ　　下余量 = UceQ − Uces　　最大不失真幅度 = 两者中较小的

Q 点放在负载线中点附近，UceQ ≈ (Vcc + Uces) / 2，两边余量相等，输出能摆得最大。本页只考虑空载，接了负载后要看交流负载线，思路相同。

面试怎么答

常见追问

什么是静态工作点？为什么要设置？

静态工作点是没有输入信号时的 Ib、Ic、Uce。发射结有约 0.6 V 的死区，不加偏置，小信号根本进不去，大信号也只剩半个周期。设好 Q 点让管子始终工作在放大区，交流信号围绕它变化，才不失真。

固定偏置电路的 Q 点怎么算？

Ib = (Vcc − 0.7) / Rb，Ic = β·Ib，Uce = Vcc − Ic·Rc。算完验证 Uce 大于饱和压降，确认在放大区。

Q 点应该设在哪里？

负载线中点附近，UceQ 约为 Vcc 的一半。这样往上到截止、往下到饱和的余量相等，最大不失真输出幅度最大。小信号放大器为了省电可以把 Q 点设低一些，只要余量够用。

固定偏置有什么缺点？

Ic = β·(Vcc − 0.7) / Rb，Q 点和 β 成正比。β 离散性大、随温度上升，Q 点就会漂，严重时进入饱和。实际常用分压偏置加发射极电阻来稳定。
