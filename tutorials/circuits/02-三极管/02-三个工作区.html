三极管 · 截止 放大 饱和

三个工作区

同一只三极管，两个结怎么偏置，决定它是断开的开关、线性放大器，还是闭合的开关。面试常让你拿到一个电路，判断管子在哪个区。

判断依据 · 两个结

看两个结的偏置

三极管有两个结，每个结要么正偏要么反偏，组合出三个常用工作区。以 NPN 为例：

工作区发射结集电结NPN 电位关系IcUce用途
截止零偏或反偏反偏Ube < 约 0.5 V≈ 0，只有漏电流≈ Vcc开关断开
放大正偏反偏Uc > Ub > UeIc = β·Ib，受 Ib 控制介于 0.3 V 与 Vcc 之间放大电路
饱和正偏正偏Ub > Ue 且 Ub > UcIc < β·Ib，由外电路决定Uces ≈ 0.1~0.3 V（典型值）开关闭合

饱和这一行最容易答错。饱和不是"电流最大"那么简单：因为集电极电阻限死了电流，Ic 最多只有 (Vcc − Uces) / Rc，再加大 Ib 也涨不上去，所以 Ic < β·Ib，β 在这里不再成立。

负载线 · 工作点

拖动 Ib，工作点沿负载线走

集电极回路满足 Uce = Vcc − Ic·Rc，这是一条直线，叫直流负载线。管子自己的特性是一族曲线，Ib 选中其中一条。两者的交点就是工作点。Ib 从零往上加，工作点从右下的截止区，沿负载线往左上走，穿过放大区，最后卡在左边的饱和区。

做题套路

先假设放大，再验证

拿到一个固定偏置电路，四步判断：① 先算 Ib；② 假设在放大区，Ic = β·Ib；③ 算 Uce = Vcc − Ic·Rc；④ 验证：Uce 大于饱和压降，假设成立；算出来 Uce 很小甚至为负，说明假设错了，管子饱和，改用 Ic = (Vcc − Uces) / Rc。Ib = 0 或发射结没正偏，就是截止。

面试怎么答

常见追问

三极管三个工作区的条件分别是什么？

截止：发射结零偏或反偏，集电结反偏，Ic ≈ 0。放大：发射结正偏，集电结反偏，Ic = β·Ib。饱和：两个结都正偏，Uce 只剩 0.1~0.3 V，Ic 由外电路决定。

饱和时 Ic 为什么小于 β·Ib？

因为集电极回路里的电阻把电流限死了，Ic 最多是 (Vcc − Uces) / Rc。Ib 再大，Ic 也涨不上去，多出来的基极电流只是让管子饱和得更深。所以饱和区里 β 关系不成立。

怎么判断一个电路里三极管处于哪个区？

先看发射结有没有正偏，没有就是截止。正偏的话先假设放大，算 Ic = β·Ib，再算 Uce = Vcc − Ic·Rc。Uce 还大于饱和压降，假设成立；算出来很小或是负的，就是饱和。

做开关时为什么要让三极管深度饱和？

饱和时 Uce 最小，管耗 Uce·Ic 最小，负载拿到的电压最多。设计时通常让 β·Ib 是所需 Ic 的 2~10 倍（经验值），因为 β 离散性大，留足余量才能保证每只管子都饱和。代价是退出饱和慢，关断有存储时间。
