三极管 · 电流放大系数

β 放大倍数

β 是三极管最出名的参数，但它一点都不"准"：随电流变、随温度变、同型号之间还差好几倍。这页讲清 β 从哪来、怎么量、为什么设计时不能指望它。

定义 · α 与 β

β 和 α：同一件事的两种说法

发射极流出的电流 Ie 在管子里分成两股：绝大部分被集电极收走，成为 Ic；一小部分在基区复合掉，由基极补上，成为 Ib。

Ie = Ib + Ic　　α = Ic / Ie　　β = Ic / Ib

β = α / (1 − α)　　α = β / (1 + β)

α 总是略小于 1，典型 0.98~0.998。因为 β 的分母是 1 − α，α 只要往 1 靠近一点点，β 就翻倍。这就是为什么 β 对工艺这么敏感。

直流 hFE · 交流 β

hFE 看比值，交流 β 看斜率

手册里的 hFE 是直流电流增益：在某个工作点上 Ic 除以 Ib，几何上是原点到工作点连线的斜率。交流 β（也写作 hfe）是小信号增益：ΔIc / ΔIb，几何上是曲线在工作点的切线斜率。Ic–Ib 曲线如果是直线，两者相等；实际曲线会弯，两者就不同。

β 会变 · 电流与温度

β 随 Ic 和温度变化

β 只在中等电流时比较平坦。小电流时，发射结耗尽区和表面的复合电流在 Ib 里占比变大，β 下降；大电流时出现大注入效应和基区展宽（Kirk 效应），β 也下降。温度升高，少子寿命变长、复合变少，β 增大，教材常用的数字是每升高 1 °C 增加 0.5%~1%。

设计原则

为什么设计不能依赖精确的 β

除了电流和温度，β 还有很大的离散性。同一型号、同一批次，β 也可能差几倍。以 2N3904 为例，手册在 Ic = 10 mA 时给的 hFE 是 100~300（最小值到最大值）。所以好电路的指标不应该跟着 β 走：

用途怎么摆脱 β结果
开关按最小 β 设计，再让基极电流过驱动，强制 β = Ic / Ib 取 10~20（经验值）β 再小也能饱和
偏置分压偏置加发射极电阻 Re，让 Ic ≈ (Ub − 0.7) / Re工作点由电阻决定，见 静态工作点、热漂移
放大发射极串电阻做负反馈，电压增益 ≈ −Rc / Re增益由电阻比决定，见 分压偏置

面试时这样说：β 是个"大而不准"的数。我们利用它大，靠负反馈让结果和它的具体值无关。

面试怎么答

常见追问

β 和 α 是什么关系？

α = Ic / Ie，β = Ic / Ib。因为 Ie = Ib + Ic，所以 β = α / (1 − α)。α 典型 0.98~0.998，对应 β 约 50~500。α 接近 1 时，α 一点点变化就让 β 大幅变化。

hFE 和 β 有什么区别？

hFE 是直流增益，某一工作点的 Ic / Ib；交流 β 是小信号增益，ΔIc / ΔIb，是特性曲线在工作点的斜率。偏置计算用 hFE，小信号分析用交流 β，中等电流下两者接近。

β 受哪些因素影响？

三个：一是 Ic，小电流和大电流时都下降，中间有峰值；二是温度，温度升高 β 增大，约每度 0.5%~1%；三是个体离散性，同型号能差几倍。

既然 β 这么不稳定，电路怎么保证性能一致？

开关电路按最小 β 设计并过驱动，保证深度饱和。放大电路用分压偏置加发射极电阻做负反馈，让工作点和增益由电阻决定，基本不受 β 影响。
