Buck 拓扑

Buck 只有五个元件：上管开关、续流二极管（或下管）、电感、输出电容、负载。开关一开一关，电感一充一放，输出就是输入按占空比打折：Vout = D·Vin。

电路 · 两个状态

开关导通和关断，电流各走哪条路

波形 · 公式 · CCM 与 DCM

SW 电压和电感电流长什么样

SW 节点是一个在 Vin 和地之间跳的方波，LC 把它平均一下就是 Vout，所以 Vout = D·Vin。电感电流是三角波：导通时电感两端是 Vin − Vout，电流按斜率 (Vin − Vout)/L 上升 D·T 这么久，涨出来的就是纹波。

Vout = D·Vin　　ΔIL = (Vin − Vout)·D / (L·f)　　Ipk = Iout + ΔIL / 2

负载电流小到 Iout < ΔIL / 2 时，三角波的谷底碰到零。二极管不能反向导电，电流就停在零，这叫断续模式 DCM。平时的状态叫连续模式 CCM。

推导 · 白板画法

Vout = D·Vin 是怎么来的

稳态时电感电流每个周期回到原值，所以电感上的伏秒必须平衡：导通时正向"充"进去的，等于关断时反向"放"出来的。

(Vin − Vout)·D·T = Vout·(1 − D)·T　→　Vout = D·Vin

白板上按下面的顺序画，面试官最想听的是第 4、5 步：

  1. 左边画 Vin 和输入电容 Cin，底下一条地线贯穿到右边。
  2. 横线上串上管 Q1，右边的连接点标 SW。
  3. SW 往下画续流二极管到地，阴极朝上接 SW。同步 Buck 换成下管 Q2。
  4. SW 往右串电感 L 到 Vout，Vout 往下画 Cout 和负载。
  5. 分两种颜色画电流：Q1 导通时 Vin → Q1 → L → 负载 → 地；Q1 关断时 地 → D → L → 负载 → 地。
  6. 旁边补一句：输出电压 D·Vin，电感电流三角波，纹波 ΔIL = (Vin − Vout)·D / (L·f)。

Buck 的输入电流是断续的脉冲（只在 Q1 导通时有电流），所以 Cin 必须靠近 Q1 和二极管，这个回路的面积决定了尖峰噪声。输出电流经过电感是连续的，输出纹波相对小。

面试怎么答

常见追问

画一下 Buck，讲讲它怎么工作？

上管导通时，SW 接到 Vin，电感两端是 Vin − Vout，电流上升，电感储能，同时给负载供电。上管关断时，电感电流不能突变，它把 SW 拉到地以下，续流二极管导通，电流沿 地 → 二极管 → 电感 → 负载 形成回路，电感放能，电流下降。按伏秒平衡得到 Vout = D·Vin。

续流二极管去掉会怎样？

上管一关，电感电流没有通路，L·di/dt 会产生很高的负压尖峰，把上管击穿。续流二极管就是给电感电流留一条路。

什么是 CCM 和 DCM？边界在哪？

CCM 是电感电流始终大于零，DCM 是每个周期里有一段电流为零。边界是 Iout = ΔIL / 2。DCM 下 Vout = D·Vin 不再成立，同样的占空比输出会偏高，闭环会自动把占空比调小。同步 Buck 在强制 PWM 下电流可以反向，不进 DCM。

同步 Buck 和异步 Buck 有什么区别？

同步 Buck 用下管 MOS 替代续流二极管，压降从 0.3~0.5 V 降到 Iout·Rds(on)，低压大电流时效率高得多。代价是需要两路互补驱动和死区时间，防止上下管直通。

电感值怎么定？

先定纹波，一般取 ΔIL 为 20%~40% 的 Iout，再用 L = (Vin − Vout)·D / (f·ΔIL) 算，Vin 取最大值。然后核对饱和电流大于峰值电流。详细见 电感选型。
