反馈环路稳定性

开关电源靠负反馈稳压。反馈太弱，稳压不准、响应慢；反馈太猛、相位又落后太多，负反馈就变成正反馈，输出振铃甚至自激。这页回答两个问题：稳定看什么指标，补偿零点和穿越频率怎么定。

闭环框图 · 环路增益 T

误差绕一圈回来，被放大了多少

分压网络 H 把 Vout 缩小后和基准 Vref 比较，误差经误差放大器和补偿网络 Gc 放大，去调 PWM 占空比，功率级 Gp 再把占空比变成输出电压。信号沿这个环绕一圈的总增益叫环路增益：

T = Gc·Gp·H　　扰动到输出：d → d / (1 + T)

低频时 |T| 很大，负载跳变、输入纹波这类扰动被压小 |T| 倍，这就是稳压精度的来源。频率越高 |T| 越小，|T| = 1（0 dB）的频率叫穿越频率 fc，再往上环路就管不了了。麻烦在相移：每个极点都让信号更落后，如果到 fc 附近相移已经接近 −180°，负反馈就变成正反馈，1 + T 接近 0，扰动反而被放大。

相位裕度 · 增益裕度 · 阶跃响应

伯德图上读两个裕度

在环路增益 T 的伯德图上找两个点。幅频曲线穿过 0 dB 的频率是 fc，这时相位离 −180° 还差多少，就是相位裕度 PM。相位到达 −180° 的频率上，增益比 0 dB 低多少，就是增益裕度 GM。

PM = 180° + ∠T(fc)　　GM = −20·lg|T(f180)|

工程判据（典型值）：PM > 45°，通常取 45°~60°；GM > 6~10 dB；fc 取开关频率的 1/10~1/5。PM 越小，阶跃响应振铃越多；PM 接近 90° 也不是越大越好，往往说明增益给得保守，响应偏慢。fc 越高，负载跳变时下冲越小，良好阻尼时 ΔV ≈ ΔI / (2π·fc·Cout)。但 fc 不能逼近 fsw/2：PWM 每个周期才更新一次占空比，是采样系统，fsw/2 附近有额外相移，开关纹波也会被环路放大。

看现象反推补偿

现象原因调法
负载跳变后连续振铃fc 处相移太大：零点放得比 fc 还高，或 fc 太靠近 fsw/2零点往低频挪到 fc/10 附近，或降低 fc
下冲大、回得慢fc 太低，环路反应慢加大补偿增益，把 fc 提到 fsw 的 1/10 左右；或加大 Cout
恢复带一条长拖尾零点太低，恢复尾巴的时间常数约 1/(2π·fz)零点提高到 fc/10 附近，用一点相位裕度换恢复速度
只在某个负载或输入电压下振荡输出极点随负载移动，环路增益随 Vin 变化按最坏情况校核：最大 Vin、最小有效 Cout（算上直流偏压降额）、轻载和满载
电解电容换成陶瓷后不稳ESR 零点原本在帮忙补相位，换成陶瓷后跑到很高的频率重新补偿；电压模式改用 Type III

电压模式和电流模式的补偿不一样。电压模式 Buck 的功率级是 LC 低通，谐振频率附近相位骤降接近 180°，要用带两个零点的 Type III 补偿把相位抬回来。电流模式先用内环控制电感电流，电感相当于受控电流源，功率级只剩一个输出极点，用一个零点的 Type II 就够，所以好补偿得多。

实测环路：在反馈分压电阻的上端串一个 10~50 Ω 的注入电阻，环路分析仪经隔离变压器在电阻两端注入小信号扫频，两端信号之比就是 T，直接得到伯德图。没有仪器时用电子负载做阶跃：振铃在一两个周期内衰减完，相位裕度大致够；振铃一串，裕度就不够。

面试怎么答

常见追问

怎么判断一个开关电源的环路稳不稳定？

测环路增益 T = Gc·Gp·H 的伯德图，看两个裕度：穿越频率处相位裕度大于 45°，通常取 45°~60°；相位到 −180° 处增益裕度大于 6~10 dB。穿越 0 dB 时斜率最好是 −20 dB/十倍频。没有环路分析仪就做负载阶跃，看振铃多少。

相位裕度为什么要 45° 以上？越大越好吗？

相位裕度小，fc 附近 1 + T 接近 0，扰动不但不被压下反而被放大，阶跃响应就振铃。元件容差、温度、负载和输入电压变化都会吃掉裕度，所以要留余量。也不是越大越好，接近 90° 一般说明增益给得保守，响应慢。60° 左右兼顾阻尼和速度。

穿越频率为什么取开关频率的 1/10~1/5？

fc 越高，负载跳变时下冲越小，ΔV ≈ ΔI / (2π·fc·Cout)，恢复也越快。但 PWM 每个开关周期才更新一次占空比，是采样系统，fsw/2 附近有额外相移，fc 一靠近相位裕度就迅速变差；开关纹波也会进入环路被放大，造成占空比抖动。1/10~1/5 是两者的折中。

补偿零点放在哪？

电流模式用 Type II，零点一般放在 fc 的 1/10 附近，不低于输出极点。零点在 fc 处补回将近 +90° 的相位，抵消输出极点的相移，相位裕度就够。零点离 fc 太近甚至更高，fc 处相位接近 −180°，会振铃；放得太低，相位裕度虽然大，但负载跳变后恢复尾巴的时间常数约 1/(2π·fz)，拖得很长。电压模式用 Type III，两个零点放在 LC 谐振频率附近。

环路增益怎么实测？

在反馈分压电阻上端串一个 10~50 Ω 的注入电阻，用环路分析仪经隔离变压器注入扫频小信号，测电阻两侧的信号比，就是环路增益的幅度和相位。注入幅度要小，保证电路工作在线性区。
