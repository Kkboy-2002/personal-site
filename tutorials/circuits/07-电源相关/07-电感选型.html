电感选型

选电感只看四个参数：感值定纹波，饱和电流 Isat 管峰值，温升电流 Irms 管发热，直流电阻 DCR 管导通损耗。最容易踩的坑是只看感值和额定电流，峰值电流一碰到 Isat，感量骤降，电流失控。

感值 · 纹波比例

感值由纹波电流决定

电感把 SW 节点的方波电压变成平滑的电流。电压一定时，感值越大电流变化越慢，纹波越小。所以先定允许的纹波 ΔIL，再反推感值：

L = (Vin − Vout)·D / (f·ΔIL)　　ΔIL 一般取 Iout 的 20%~40%

纹波取太小，电感要很大，体积大、DCR 大，负载突变时电流也爬得慢；纹波取太大，峰值电流高，输出纹波和磁芯损耗都大，轻载时更早进入 DCM。输入电压有范围时按最高 Vin 算，那时纹波最大。

饱和电流 Isat · 峰值

峰值电流一碰 Isat，感量骤降

感量来自磁芯。电流越大磁通越大，磁芯一饱和，导磁率骤降，感量跟着掉。厂家把感量下降到某个比例（常见 20%~30%，各家定义不同）时的电流标为 Isat。要拿来比较的是峰值电流，不是平均电流：

Ipk = Iout + ΔIL / 2 < Isat，留余量，并且要大于芯片的限流值

感量一掉，同样的电压下 di/dt = V / L 变大，电流斜率变陡，峰值冲得更高，磁芯饱和得更深，这是正反馈。铁氧体饱和得很"硬"，过了拐点感量断崖式下跌；合金粉芯是"软"饱和，感量随电流慢慢降，过载时不容易失控。

Irms · DCR · 选型步骤

Isat 和 Irms 不是一回事

Isat 是磁的指标，看峰值，超了感量掉。Irms 是热的指标，看有效值，超了温升过高，厂家常按温升 40 °C 标定。两个都要满足，数据手册里两个值可能差很多，以较紧的那个为准。

Irms = √(Iout² + ΔIL²/12)　　P_DCR = Irms²·DCR

DCR 是绕组的直流电阻，损耗和电流平方成正比，大电流时是电感损耗的大头。同样尺寸下感值越大，匝数越多、线越细，DCR 越大。纹波电流还会带来磁芯损耗和绕组交流损耗，纹波越大、频率越高越明显，要用厂家的损耗计算工具核对。

参数管什么怎么核对

选型步骤：

  1. 按最高 Vin、纹波取 Iout 的 20%~40% 算出感值，取相近的标准值。
  2. 用选定的感值重算 ΔIL 和峰值 Ipk = Iout(max) + ΔIL/2。
  3. 选 Isat 大于 Ipk 并留 20%~30% 余量的型号。芯片有逐周期限流时，最好 Isat 大于限流值，输出短路时也不饱和。
  4. 核对 Irms 额定值大于实际有效值，算 DCR 损耗和温升。
  5. 最后看尺寸、屏蔽和成本；频率高时再核对磁芯损耗。
面试怎么答

常见追问

Buck 的电感怎么选？

先定纹波，ΔIL 取 Iout 的 20%~40%，按最高 Vin 用 L = (Vin − Vout)·D / (f·ΔIL) 算感值。再算峰值 Iout + ΔIL/2，选 Isat 比它大并留余量的型号，最好大于芯片限流值。然后核对 Irms 额定值和 DCR 损耗，最后看尺寸和屏蔽。

Isat 和 Irms 有什么区别？

Isat 是饱和电流，磁芯的指标，感量降到规定比例（常见 20%~30%）时的电流，要和峰值电流比。Irms 是温升电流，发热的指标，通常指温升 40 °C 时的有效值电流，要和有效值比。两个都得满足。

电感饱和了会发生什么？

感量骤降，di/dt = V / L 变大，电流斜率变陡，峰值冲得更高，磁芯饱和得更深，形成正反馈。结果是开关管过流、芯片频繁触发限流、纹波和发热变大，严重时烧管子。铁氧体是硬饱和，过了拐点感量断崖式下跌，更危险。

感值选大一点好还是小一点好？

不是越大越好。感值大，纹波和峰值电流小，输出纹波小，但体积大、DCR 大，负载突变时电流爬升 (Vin − Vout)/L 慢，瞬态响应差。感值小则相反。所以取 ΔIL 为 Iout 的 20%~40% 这个折中。

为什么 DC-DC 常用一体成型电感？

一体成型多用合金粉芯，是软饱和，过载时感量慢慢降，不会突然失控；磁芯把线圈包住，屏蔽好、漏磁小；体积小、耐冲击。代价是磁芯损耗一般比铁氧体大，高频时要核对。
