运放 · 抗干扰能力

CMRR 与 PSRR

理想运放只放大两个输入端的差，对两端一起变的电压、对电源上的波动都不理会。实际运放会漏过来一点，漏多少就用 CMRR 和 PSRR 衡量，而且频率越高漏得越多。

共模抑制比 · CMRR

两个输入一起动，输出也会动一点

两个输入端的平均电压叫共模电压 Vcm。理想情况下它对输出没有影响，实际上会以一个很小的共模增益 Ac 漏到输出。CMRR 就是差模增益和共模增益之比：

Vo = Ad·Vd + Ac·Vcm，CMRR = 20·log(Ad / Ac)

更好用的理解方式是把它折算到输入端：共模电压 Vcm 相当于在输入端加了一个 Vcm / CMRR 的误差电压，再和信号一起被放大。例如 CMRR 80 dB 即 1 万倍，1 V 共模就相当于 100 µV 的输入误差。

实际的差分放大电路里，外接四个电阻的匹配往往比运放本身的 CMRR 更要命。最坏情况下 CMRR ≈ (1 + G) / (4·ε)，ε 是电阻相对误差。增益 1、用 1% 电阻，最坏只有约 50 倍，即 34 dB。详见 差分放大器。

电源抑制比 · PSRR

电源上的纹波会漏到输出

PSRR 衡量电源电压变化对运放的影响，通常折算到输入端：电源变化 ΔVs 引起的等效输入失调变化为 ΔVs / PSRR，再按噪声增益放大到输出。

PSRR = 20·log(ΔVs / ΔVos)，输出纹波 ≈ 电源纹波 / PSRR · 噪声增益

和 CMRR 一样，PSRR 在低频很高，到几十 kHz 以后就只剩几十 dB。开关电源的纹波恰好在 100 kHz 到 MHz 这一段，运放自己挡不住，要靠电源引脚旁边的去耦电容和滤波把高频纹波先吃掉。

面试怎么答

常见追问

什么是 CMRR？

共模抑制比，差模增益和共模增益之比，用 dB 表示，CMRR = 20·log(Ad / Ac)。它表示运放对两个输入端同时变化的电压有多不敏感。折算到输入端，共模电压 Vcm 相当于 Vcm / CMRR 的误差电压。

用运放搭的差分放大器，CMRR 主要由什么决定？

通常由外接四个电阻的匹配决定，而不是运放本身。最坏情况 CMRR ≈ (1 + G) / (4·ε)，增益 1、1% 电阻时只有约 34 dB。要高 CMRR，就用 0.1% 以下的精密电阻、匹配电阻网络，或者直接用仪表放大器。

PSRR 是什么？为什么高频时要靠去耦电容？

电源抑制比，衡量电源波动漏到输出的程度。它在低频很高，但随频率大约按 20 dB / 十倍频下降，100 kHz 时可能只剩几十 dB。开关电源纹波正好在这一段，运放自己挡不住。去耦电容在高频阻抗很低，和电源走线阻抗组成低通，把高频纹波在进引脚之前就旁路到地。

为什么 CMRR 和 PSRR 会随频率下降？

它们都靠运放内部的高增益和电路对称来抑制干扰。频率升高后开环增益下降，内部寄生电容又让两边不再对称，所以抑制能力变差。

正电源和负电源的 PSRR 一样吗？

常常不一样，数据手册会分开给出 PSRR+ 和 PSRR−，高频时差别更明显。设计时按较差的那一路算，两路电源都要去耦。
