运放 · 基本放大电路

同相放大器

信号从同相端进，输出和输入同相，输入阻抗极高。把 Rf 短路、Rg 断开，就成了电压跟随器，专门用来隔离和缓冲。

推导 · 同相放大与跟随器

Vo = (1 + Rf / Rg)·Vin

信号直接接同相端，Rf 从输出接回反相端，Rg 从反相端接地。反馈仍然接在反相端，是负反馈。

  1. 虚短：V− ≈ V+ = Vin。注意这里反相端不是虚地，而是跟着 Vin 走。
  2. Rg 上的电流 I = Vin / Rg，方向从反相端流向地。
  3. 虚断：这个电流全部来自 Rf，所以 Vo = Vin + I·Rf = (1 + Rf / Rg)·Vin。

信号源只接在运放的同相输入脚上，而输入脚几乎不取电流，所以输入阻抗就是运放自身的输入阻抗，MΩ 到 TΩ 级。增益最小是 1，不能做衰减。

Rf = 0、Rg 开路时，增益 = 1 + 0 = 1，这就是电压跟随器：输出等于输入，输入阻抗极高，输出阻抗极低。

跟随器 · 缓冲隔离

增益只有 1，为什么还要用跟随器

跟随器不放大电压，它的作用是阻抗变换：输入端几乎不取电流，输出端能提供几十毫安。高内阻的信号源，比如电阻分压出来的参考电压，直接接重负载会被拉垮；中间隔一个跟随器，源只看到运放的高输入阻抗，负载电流改由运放的电源提供。

同相接法的代价是输入端有共模电压：两个输入脚都跟着 Vin 上下走。所以 Vin 必须落在运放的输入共模范围内，而且有限的 CMRR 会带来额外误差，详见 CMRR 与 PSRR。跟随器的共模摆幅最大，单电源场合要特别留意 轨到轨 问题。

面试怎么答

常见追问

推一下同相放大器的增益。

虚短 V− = Vin；Rg 上电流 Vin / Rg；虚断，这个电流全部流过 Rf；所以 Vo = Vin + (Vin / Rg)·Rf = (1 + Rf / Rg)·Vin。

同相放大器和反相放大器的区别？

同相输出同相、输入阻抗极高、增益至少为 1，但输入端有共模电压。反相输出反相、输入阻抗等于 Rin、增益可以小于 1，两个输入端都在 0 V，没有共模问题。

电压跟随器增益是 1，有什么用？

做阻抗变换。输入阻抗极高，不拖累前级；输出阻抗极低，能带负载。典型用法是缓冲电阻分压出来的参考电压、驱动 ADC 输入，或者隔离前后级。

跟随器的反相端能不能串一个电阻？

可以。因为虚断，反馈电阻上没有电流，增益仍是 1。有时故意串一个和源内阻相等的电阻，用来平衡偏置电流；或者限制输入保护二极管的电流。

跟随器直接驱动大电容负载会怎样？

容易振荡。跟随器是 100% 反馈，环路带宽最宽，相位裕度最小，输出电阻和负载电容再加一个极点就可能不稳。常见做法是输出串一个几十欧的隔离电阻。
