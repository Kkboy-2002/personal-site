运放 · 基本放大电路

反相放大器

面试白板最常考的运放电路。用虚短和虚断四步推出增益，再看输入阻抗为什么只有 Rin、输出为什么会削顶。

推导 · 四步

用虚短、虚断推出 Vo = −(Rf / Rin)·Vin

先画对电路：信号经 Rin 进反相端，Rf 从输出接回反相端，同相端接地。反馈接在反相端，是负反馈，所以虚短可以用。

  1. 同相端接地，V+ = 0。虚短，所以 V− ≈ 0。反相端电位是 0 却没有接地，这叫虚地。
  2. Rin 两端电压是 Vin − 0，所以流过 Rin 的电流 I = Vin / Rin。
  3. 虚断，运放输入端不取电流，所以这个 I 全部流过 Rf。
  4. Rf 左端是 0 V，电流从左往右流过 Rf，所以 Vo = 0 − I·Rf = −(Rf / Rin)·Vin。

Vo = −(Rf / Rin)·Vin　　输入阻抗 = Rin

负号表示输出和输入反相，正弦波就是相位差 180°。增益只由两个电阻的比值决定，和运放自身的 A 基本无关，这正是负反馈的好处。

输入阻抗 · 缺点

输入阻抗只有 Rin，会被信号源内阻吃掉增益

因为反相端是虚地，从输入端看进去就是 Rin 直接接地，所以输入阻抗 = Rin。信号源都有内阻 Rs，它和 Rin 串联，等于给 Rin 多加了一截。电流变小，增益跟着变小。

实际增益 = −Rf / (Rs + Rin)

设计要点

实际电路怎么取值

问题做法原因
Rin 取多大先按信号源内阻定，Rin 至少大于 Rs 的 100 倍输入阻抗就是 Rin，太小会拖垮信号源
Rf 取多大Rf = |增益|·Rin，一般不超过几百 kΩ 到 1 MΩ太大时偏置电流误差和热噪声变大
同相端接什么常接一个 Rp = Rin ∥ Rf 到地让两个输入端看出去的电阻相等，偏置电流产生的压降相互抵消
输出摆幅|Vo| 峰值留在饱和电压以内否则削顶，虚短失效，公式不再成立
高频稳定性Rf 上可并一个小电容限制带宽、抵消反相端寄生电容带来的相移

和同相放大器比：反相放大器的两个输入端都在 0 V，没有共模电压，精度好；代价是输入阻抗低、输出反相。要高输入阻抗就用 同相放大器。

面试怎么答

常见追问

画一个反相放大器，推它的增益。

同相端接地，虚短得 V− = 0；Rin 上电流 Vin / Rin；虚断，这个电流全部流过 Rf；所以 Vo = −(Rf / Rin)·Vin。

反相放大器的输入阻抗是多少？

等于 Rin。因为反相端是虚地，从输入端看进去就是 Rin 接到地。所以它不适合接内阻大的信号源。

什么是虚地？它能当地用吗？

虚地是反相端电位近似为 0，但不是真的接地。它靠负反馈维持，不能把别的电流灌进去当地线用。输出饱和后虚地也就不存在了。

同相端为什么要接一个 Rin ∥ Rf 的电阻？

为了平衡偏置电流。两个输入端的偏置电流差不多，让它们各自看到的直流电阻相等，产生的压降就能抵消，输出只剩失调电流带来的误差。

输出为什么会削顶？

输出最多只能摆到电源轨附近。理想输出 |Rf / Rin|·Vin 超过这个范围，输出就被卡住，波形顶部被削平。要么降低增益或输入，要么提高供电，或者换轨到轨输出的运放。
