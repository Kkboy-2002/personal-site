运放 · 波形运算

积分电路

把反相放大器的反馈电阻换成电容，输出就变成输入对时间的积分：方波进去，三角波出来。可它对直流误差也照样积分，所以实际电路总要在电容旁边并一个大电阻。

推导 · 电容代替 Rf

Vo = −(1 / (R·C))·∫Vin dt

电路和反相放大器一样：信号经 R 进反相端，同相端接地，只是反馈元件从电阻换成了电容 C。

  1. 同相端接地，虚短得 V− ≈ 0，反相端是虚地。
  2. R 上的电流 I = Vin / R，只由 Vin 决定。
  3. 虚断，这个电流全部流进电容。电容电压 = 电荷 / C，而电荷就是电流对时间的累加。
  4. 电容左端是 0 V，所以 Vo = −(1/C)·∫I dt = −(1/(R·C))·∫Vin dt。

Vo = −(1 / (R·C))·∫Vin dt　　输出斜率 dVo/dt = −Vin / (R·C)

方波在 +A 和 −A 之间跳。每半个周期里 Vin 不变，电容被恒流充电，输出按固定斜率 A / (R·C) 直线下降或上升，拼起来就是三角波。每半个周期输出变化 A·(T/2) / (R·C)，这就是三角波的峰峰值：

三角波峰峰值 = A / (2·f·R·C)

实际电路 · 并联 Rf

直流误差也被积分，输出一路漂到电源轨

电容对直流相当于开路。理想积分器对直流没有负反馈，直流增益就是运放的开环增益，十万倍以上。

运放总有失调电压 Vos 和偏置电流 Ib，它们相当于一个很小的直流输入。积分器把它一直累加，输出单向爬升，迟早撞到电源轨。撞上以后三角波有一边被削掉，电路就不能用了。

漂移速率 = Vos / (R·C) + Ib / C

解决办法是在电容两端并一个大电阻 Rf。直流下电容开路，只剩 Rf，电路退化成增益 −Rf / R 的反相放大器，输出偏移被限制住。代价是低频不再积分，只有频率远高于 fL 的信号才被正常积分。

输出直流偏移 = Vos·(1 + Rf / R)　　fL = 1 / (2π·Rf·C)

频率特性 · 用途

换个角度看：积分器是一个低通

对正弦信号，电容的阻抗是 1 / (2π·f·C)。把它当成反相放大器里的 Rf，增益就是 1 / (2π·f·R·C)。频率每升高十倍，增益降到十分之一，也就是 −20 dB/十倍频。增益等于 1 的频率叫单位增益频率 f0 = 1 / (2π·R·C)。

并了 Rf 以后，低于 fL 的频率增益被限制在 Rf / R，整个电路就是一阶有源低通滤波器。只有在 fL 以上，它才表现为积分。

输入输出原因
方波三角波每半个周期恒流充电，斜率 A / (R·C) 不变
正弦余弦，超前输入 90°积分带来 −90°，反相再加 180°；幅度 A / (2π·f·R·C)
直流或阶跃斜坡，直到饱和恒定输入就是恒流充电，Vos 漂移就是这个过程
三角波由抛物线段拼成，接近正弦斜坡积分后变成二次曲线

常见用途：PI 调节器和开关电源误差放大器的补偿网络，靠积分项消除稳态误差；积分器加比较器组成三角波、锯齿波发生器；双积分型 ADC。需要每次从零开始积分的场合，会在电容两端并一个模拟开关，积分前先把电容放电复位。

面试怎么答

常见追问

画一个积分电路，推它的输出。

反相放大器把 Rf 换成电容。同相端接地，虚短得反相端是虚地，R 上电流 Vin / R；虚断，这个电流全部给电容充电；电容左端 0 V，所以 Vo = −(1/C)·∫(Vin / R) dt = −(1/(R·C))·∫Vin dt。

输入方波，输出是什么？幅度怎么算？

三角波。半个周期里 Vin = ±A 不变，电容恒流充电，输出斜率 A / (R·C) 不变。半个周期 T/2 内输出变化 A·T / (2·R·C)，这就是峰峰值，写成频率是 A / (2·f·R·C)。频率越高，三角波越小。

为什么实际积分电路要在电容上并一个电阻？

电容隔直，理想积分器对直流没有反馈，直流增益就是开环增益。失调电压和偏置电流被不停累加，输出以 Vos / (R·C) + Ib / C 的速度漂移，最后饱和。并上 Rf，直流增益被限制在 Rf / R，输出偏移只剩 Vos·(1 + Rf / R) 这个量级。

并联的 Rf 取多大？

两头都有约束。Rf 太大，直流增益高，偏移大；Rf 太小，fL = 1 / (2π·Rf·C) 升高，信号频率附近就不像积分了，三角波变圆。先让信号最低频率比 fL 高 10 倍以上，再核对 Vos·(1 + Rf / R) 能不能接受。

积分器的频率特性是什么样的？

增益 1 / (2π·f·R·C)，每十倍频下降 20 dB，输出超前输入 90°（含反相的 180°）。单位增益频率 f0 = 1 / (2π·R·C)。并 Rf 后是一阶低通，直流增益 Rf / R，转折频率 fL = 1 / (2π·Rf·C)。
