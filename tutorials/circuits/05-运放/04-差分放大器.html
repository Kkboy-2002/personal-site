运放 · 基本放大电路

差分放大器

只放大两个输入的差，把两边共有的干扰扔掉。四个电阻就能搭，但电阻一失配，共模干扰就漏到输出；仪表放大器是为了解决这个问题。

四电阻差分 · 电阻匹配

Vo = (R2 / R1)·(V2 − V1)

它是反相放大器和同相放大器的叠加。V1 经 R1 进反相端，V2 经 R3、R4 分压后进同相端，R2 是反馈电阻。用叠加定理分别算：

  1. 只看 V1（V2 接地）：反相放大，贡献 −(R2 / R1)·V1。
  2. 只看 V2（V1 接地）：先被 R3、R4 分压成 V2·R4 / (R3 + R4)，再同相放大 (1 + R2 / R1) 倍。
  3. 当 R1 = R3、R2 = R4 时，第 2 项正好变成 (R2 / R1)·V2，两项合起来就是 (R2 / R1)·(V2 − V1)。

Vo = V2·R4 / (R3 + R4)·(1 + R2 / R1) − V1·R2 / R1

把输入拆成差模 Vd = V2 − V1 和共模 Vcm = (V1 + V2) / 2。电阻完全匹配时共模增益为 0；只要比值差一点点，共模就会按 Acm 漏到输出。共模抑制比 CMRR = 20·lg|Ad / Acm|，单位 dB。

仪表放大器 · 三运放结构

仪表放大器：前面加两个同相放大器

四电阻差分有两个硬伤。一是输入阻抗低且两边不相等：V1 端看进去是 R1，V2 端是 R3 + R4；信号源内阻会直接加到 R1 或 R3 上，破坏匹配。二是 CMRR 全靠电阻匹配，1% 的电阻只能做到 40 到 60 dB 量级。

仪表放大器在前面加两个同相放大器 A1、A2，信号从同相端进，输入阻抗极高。两级之间只有一个 Rg，差模电压全部加在 Rg 上并被放大 1 + 2R / Rg 倍；共模电压两边一样，Rg 上没有电流，前级只让它以增益 1 通过。后级 A3 是单位增益差分放大器，把共模减掉。

面试怎么答

常见追问

四电阻差分放大器的输出公式是什么，有什么前提？

Vo = (R2 / R1)·(V2 − V1)，前提是 R1 = R3、R2 = R4，严格说是 R2 / R1 = R4 / R3。比值不等时共模电压会漏到输出。

什么是 CMRR？电阻失配怎么影响它？

CMRR 是差模增益和共模增益之比，常用 dB 表示。四电阻差分的共模增益来自电阻比值失配，失配越大 Acm 越大，CMRR 越低。增益 10、电阻失配 1% 时只有 60 dB 左右。

仪表放大器为什么要三个运放？

前两个是同相放大器，提供极高且对称的输入阻抗，并且只放大差模、共模以增益 1 通过；第三个是差分放大器，把共模减掉。前级先把差模放大 G1 倍，所以整体 CMRR 在后级基础上再提高约 20·lg(G1) dB。

仪表放大器的增益为什么只用一个电阻设？

G = 1 + 2R / Rg，只改 Rg 就改了增益，而共模在 Rg 上不产生电流，所以改增益不会破坏共模抑制。如果改后级四个电阻，就得同时保证它们的匹配。

仪表放大器用在哪？

桥式传感器、热电偶、心电等小信号测量。这些信号差模只有 mV 级，而共模有几伏或者叠着工频干扰，源内阻还不对称。
