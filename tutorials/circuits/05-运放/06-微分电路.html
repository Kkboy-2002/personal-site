运放 · 波形运算

微分电路

把积分电路里的 R 和 C 对调，输出就变成输入的变化率：三角波进去，方波出来。可它对高频的放大倍数跟着频率一起涨，噪声被放大，电路还容易振铃甚至振荡，所以实际电路必须加补偿。

推导 · 电容放到输入端

Vo = −R·C·dVin/dt

信号经电容 C 进反相端，电阻 R 从输出接回反相端，同相端接地。

  1. 同相端接地，虚短得 V− ≈ 0，反相端是虚地。
  2. 电容左端是 Vin，右端是 0 V，电容电压就是 Vin。电容电流 I = C·dVin/dt，只在 Vin 变化时才有。
  3. 虚断，这个电流全部流过 R。
  4. R 左端是 0 V，所以 Vo = 0 − I·R = −R·C·dVin/dt。

Vo = −R·C·dVin/dt

三角波每半个周期是一段直线，斜率不变，所以输出是恒定电压；斜率一翻转，输出就跳到另一边，拼起来是方波。峰值为 A 的三角波，半个周期从 −A 走到 +A，斜率 = 2A ÷ (T/2) = 4·A·f。

方波幅度 = R·C·4·A·f

实际问题 · 噪声与振铃

频率越高放大越多，噪声和振铃一起冒出来

对正弦信号，微分器的增益是 2π·f·R·C，频率每高十倍，增益大十倍。有用信号在低频，噪声和干扰往往在高频，所以输入上几乎看不见的噪声，到输出会被放大几十上百倍。

更麻烦的是稳定性。反馈网络对运放的要求随频率升高，运放能给的开环增益却随频率下降，两条线以 40 dB/十倍频的速度相交，相位裕度接近 0。结果是每个转折处都会振铃，稍有寄生电容就直接振荡。

标准改法有两个：输入端给 C 串一个小电阻 R1，把高频增益限制在 R / R1；反馈电阻 R 上并一个小电容 Cf，让更高频率的增益往下走。代价是微分只在 f1 = 1/(2π·R1·C) 以下成立，通常让 R1·C = R·Cf。

频域 · 补偿怎么取值

从幅频曲线看振铃从哪来

闭环增益不可能高过运放的开环增益。理想微分要求的增益每十倍频升 20 dB，开环增益每十倍频降 20 dB，两条线在 fx 相交。交点附近环路相移接近 180°，闭环曲线在这里冒出一个很高的尖峰，尖峰频率就是振铃频率。

振铃频率 fx ≈ √(f0·GBW)，f0 = 1/(2π·R·C)

补偿的思路是让闭环曲线在碰到开环曲线之前先拐弯往下走。R1 太小，拐点太高，来不及；R1 太大，拐点太低，信号本身也被当成高频削掉了。

面试怎么答

常见追问

画一个微分电路，推它的输出。

输入串电容 C 到反相端，R 做反馈，同相端接地。虚短得反相端是虚地，电容电压就是 Vin，电流 C·dVin/dt；虚断，电流全部流过 R；所以 Vo = −R·C·dVin/dt。

输入三角波，输出是什么？

方波。三角波每段斜率不变，输出是恒定电压；斜率变号，输出跳到另一侧。幅度 = R·C × 斜率，峰值 A、频率 f 的三角波斜率是 4·A·f。

理想微分电路为什么实际不能用？

两个原因。一是增益 2π·f·R·C 随频率升高，高频噪声被放大得最多。二是稳定性差：反馈网络要求的增益每十倍频升 20 dB，运放开环增益每十倍频降 20 dB，交点处相位裕度接近 0，输出振铃甚至振荡。

怎么改成实用的微分电路？

输入电容前串一个小电阻 R1，把高频增益限制在 R / R1；反馈电阻上并一个小电容 Cf，让更高频率的增益下降。一般取 R1·C = R·Cf，拐点 f1 = 1/(2π·R1·C) 放在信号最高频率的几倍以上。这样在 f1 以下是微分，以上变成低通。

积分电路和微分电路各自的毛病是什么？

积分电路怕低频和直流：电容隔直，失调被一直积分到饱和，要并大电阻 Rf。微分电路怕高频：增益随频率涨，噪声和振荡是问题，要串 R1、并 Cf。一个在电容旁并电阻，一个在电容前串电阻，都是给极端频率下的增益设上限。
