二极管 · 齐纳稳压

稳压二极管应用

一个限流电阻加一个反接的稳压管，就是最简单的稳压电路。它能不能稳住，只看一件事：稳压管电流 Iz 是否始终落在 Izmin 和 Izmax 之间。

工作原理 · 电流分配

多出来的电流让稳压管吃掉

稳压管反接，工作在击穿区，两端电压基本等于 Vz。电阻 R 上的电流 IR = (Vin − Vz) / R，这份电流分成两路：负载拿走 IL，剩下的 Iz 流过稳压管。

输入升高或负载变轻，多出来的电流由 Iz 吸收，输出几乎不变。反过来 Iz 被挤到接近零，稳压管退出击穿区，输出就跟着掉下去。Iz 太大则稳压管功耗超标，会热击穿。

IR = (Vin − Vz) / R = Iz + IL

限流电阻 · 按最坏情况算

限流电阻怎么算

基本公式是 R = (Vin − Vz) / (Iz + IL)。但 Vin 和 IL 都会变，要取两个最坏情况，得到一个允许区间：

  • R 不能太大：输入最低、负载最重时，Iz 仍要 ≥ Izmin。Rmax = (Vin_min − Vz) / (Izmin + IL_max)
  • R 不能太小：输入最高、负载最轻（常按空载算）时，Iz 仍要 ≤ Izmax。Rmin = (Vin_max − Vz) / (Izmax + IL_min)

Rmin < Rmax 才有解，再从中挑一个标准阻值，并核算电阻功耗 (Vin_max − Vz)² / R。

动态电阻 · 稳压效果

动态电阻决定稳得有多好

击穿区的曲线不是绝对竖直的，斜率的倒数叫动态电阻 rz，典型几欧到几十欧。它和 R 构成分压，所以输入变化会按 rz / (R + rz) 漏到输出；负载变化相当于 R 和 rz 并联后的内阻。

ΔVo / ΔVin = rz / (R + rz)　　ΔVo / ΔIL = −(R ∥ rz)

rz 在小电流时更大（拐点附近很软），5~8 V 的管子 rz 最小。所以 Iz 不能取得太小。这种电路效率低，只适合几十 mA 以内的小电流或做基准。

面试怎么答

常见追问

稳压二极管稳压电路的原理是什么？

稳压管反接工作在击穿区，电流在很大范围内变化时两端电压基本不变。限流电阻把输入和输出之间的压差吃掉，电阻电流 = 稳压管电流 + 负载电流。输入升高或负载变轻时，多出来的电流由稳压管吸收，输出保持在 Vz。

限流电阻怎么选？

按两个最坏情况定区间。输入最低、负载最重时稳压管电流不能低于 Izmin，得到 Rmax = (Vin_min − Vz) / (Izmin + IL_max)；输入最高、负载最轻时不能超过 Izmax，得到 Rmin = (Vin_max − Vz) / (Izmax + IL_min)。在两者之间选标准值，再核算电阻功耗。

为什么不能去掉限流电阻？

稳压管击穿后动态电阻只有几欧，直接接到电源上，电流只受这几欧限制，瞬间超过 Izmax，热击穿烧毁。限流电阻既限流，又承担输入输出的压差，是电路能稳压的前提。

稳压管稳压有什么缺点？什么时候用？

效率低，为了让空载时也有 Izmin，稳压管一直在耗电；输出电流小，一般几十 mA 以内；稳压精度受动态电阻和温度系数影响。适合做小电流的偏置、基准、过压钳位。需要更大电流就用 LDO 或开关电源。

负载突然断开会怎样？

原来给负载的电流全部转到稳压管上，Iz 最大。如果设计时没按空载核算 Rmin，稳压管可能超功耗。所以 Rmin 一般按 IL_min = 0 来算。
