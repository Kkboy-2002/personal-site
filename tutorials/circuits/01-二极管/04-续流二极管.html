二极管 · 感性负载

续流二极管

继电器线圈、电机、电磁阀都是电感。电感电流不能突变，开关一断，它会产生很高的反向电压把三极管击穿。并一个二极管给电流留条路，这就是续流二极管。

关断瞬间 · V = L·di/dt

开关一断，电压为什么会冲上去

三极管导通时，电流从 Vcc 经线圈流到地，线圈里存了磁能 ½·L·I²。三极管一关，电流想在几微秒内降到零，di/dt 极大。电感为了维持电流，自己产生感应电压，下端（接集电极那端）变成正、而且很高。

V = L·di/dt　　E = ½·L·I²

按 100 mH、50 mA、1 µs 关断算，L·di/dt 约 5000 V。实际电压会被三极管 C-E 击穿或者触点拉弧钳住，但管子早已超过耐压。并上续流二极管后，线圈电流从二极管绕回自己，集电极只比 Vcc 高一个二极管压降。

波形 · 释放快慢

二极管保住了管子，却让继电器释放变慢

续流时线圈两端只有约 0.7 V 的反压，电流靠线圈电阻慢慢耗掉，按时间常数 τ = L / R 衰减，继电器要等好几个 τ 才能释放，触点分得慢，更容易拉弧。

想放得快，就要让回路里的反压更大：在二极管上串一个齐纳或 TVS。关断时 C 点被钳在 Vcc + 0.7 V + Vz，反压大了，电流下降就快。代价是 C 点电压升高，要保证它小于三极管耐压并留余量。

i(t) = (I0 + Vx / R)·e^(−t / τ) − Vx / R，Vx = 0.7 V 或 0.7 V + Vz

  • 接法：二极管反并在线圈两端，阴极接电源正，阳极接开关管那一端。接反了等于电源经二极管和三极管短路。
  • 电流：续流电流就是线圈工作电流，二极管额定电流不小于它。继电器常用 1N4148 或 1N4007。
  • 耐压：不小于电源电压并留余量。
  • 速度：继电器开关频率低，普通管就行。电机 PWM 驱动每个周期都要续流，必须用快恢复或肖特基，原因见本组第 7 页。
面试怎么答

常见追问

继电器线圈为什么要并一个二极管？

线圈是电感，电流不能突变。三极管关断时 di/dt 很大，线圈产生 L·di/dt 的感应电压，叠加在电源上加到集电极，能到几百甚至上千伏，会击穿三极管。并联二极管给线圈电流一条回路，把集电极电压钳在 Vcc + 0.7 V，线圈能量消耗在自身电阻和二极管上。

续流二极管的方向怎么接？正常工作时它导通吗？

阴极接电源正，阳极接三极管集电极。三极管导通时，阳极接近地、阴极是 Vcc，二极管反偏不导通，不影响正常工作。只有关断瞬间集电极被抬到 Vcc 以上时它才导通。

加了续流二极管有什么副作用？怎么改进？

续流回路里反压只有 0.7 V，电流按 τ = L / R 慢慢衰减，继电器释放变慢，触点分得慢容易拉弧。改进办法是加大回路反压：在二极管上串齐纳或 TVS，或串一个电阻。代价是关断时集电极电压升高，要保证小于三极管耐压。

续流二极管怎么选型？

三条：额定电流不小于负载电流；反向耐压不小于电源电压并留余量；开关频率高的场合，比如电机 PWM、Buck，要用快恢复或肖特基，普通整流管反向恢复太慢会造成大的开关损耗和尖峰。
