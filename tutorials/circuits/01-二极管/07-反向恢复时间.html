二极管 · 反向恢复

反向恢复时间

二极管从导通切到反偏，并不会立刻关断。结里存着的电荷要先被抽走，这段时间电流是反着流的。开关频率一高，这点"关不断"的时间就会变成大损耗和电压尖峰。

存储电荷 · trr = ta + tb

电流为什么会反着流一段

正向导通时，P 区的空穴注入 N 区，N 区的电子注入 P 区。这些少数载流子来不及复合，堆在结两侧，叫存储电荷。电流越大、少子寿命 τ 越长，存得越多，粗略有 Qs ≈ IF·τ。

外电路突然加上反压，存储电荷不会瞬间消失，只能靠复合，或者被反向电流抽走。抽完之前结附近仍堆满载流子，结还处在导通状态，挡不住反压。所以电流按外电路决定的 di/dt 一路下降、过零、变成反向。

ta 是从电流过零到反向电流达到峰值 IRM 的时间，这段在抽存储电荷，二极管两端电压仍接近零。tb 是结附近的少子被抽空、耗尽层重新建立之后，反向电流从 IRM 回落的时间，这时二极管才开始承受反压。

trr = ta + tb　　IRM ≈ ta·(di/dt)　　Qrr ≈ ½·IRM·trr

trr 的终点，手册一般取反向电流回落到 0.25·IRM 或 0.1·IRM。测试条件不同，数值能差好几倍，比较两颗管子时要看同一条件。

软恢复 · 硬恢复

tb 太短，电压尖峰就来了

软度 S = tb / ta，描述反向电流回落得有多"温柔"。硬恢复的管子 tb 很短，反向电流从 IRM 被突然掐断，di/dt 极大。回路里总有几十 nH 的寄生电感，它产生的 L·di/dt 叠加在反压上，形成电压尖峰和高频振铃。尖峰可能超过耐压，振铃是 EMI 的主要来源。

软恢复的管子电流慢慢回落，尖峰小得多。Qrr 相同时，因为 Qrr = ½·IRM·ta·(1 + S)，软恢复的 IRM 反而略小。外电路开关越快，di/dt 越大，IRM 越大、ta 越短，硬恢复的尖峰也越明显。

四类二极管 · 100 kHz Buck

Buck 续流为什么不能用 1N4007

异步 Buck 里，上管关断时电感电流走续流二极管；上管再开通时，二极管要从导通切换到承受 Vin 的反压。二极管还没恢复，上管就等于隔着它把 Vin 短路到地：上管电流先冲到 Io + IRM，而它两端电压还没降下来，这块重叠就是额外损耗，大部分落在上管上。

P恢复 ≈ Qrr·Vin·fsw　　P导通 ≈ VF·Io·(1 − D)

反向恢复损耗和频率成正比，每开关一次就交一次。1N4007 是给 50 Hz 工频整流设计的，trr 是 µs 级，Qrr 是 µC 级，放到 100 kHz 下每秒要交 10 万次。

面试怎么答

常见追问

什么是二极管的反向恢复时间？

二极管正向导通时，PN 结两侧存着少子电荷。突然加反压，这些电荷要先被反向电流抽走，结才能恢复阻断。从电流过零开始，到反向电流回落到规定值（如 0.25·IRM）为止，这段时间就是 trr。它分两段：ta 抽存储电荷，反向电流增大到峰值 IRM；tb 结已恢复，反向电流回落。trr = ta + tb。

为什么 Buck 的续流二极管不能用 1N4007？

1N4007 是工频整流管，trr 约 2 µs，Qrr 是 µC 级。Buck 上管每次开通，二极管都要先反向导通一段，相当于上管隔着它把输入短路，电流冲到 Io + IRM，额外损耗约 Qrr·Vin·fsw。100 kHz 下这部分能到几瓦，和输出功率一个量级，上管严重发热，还有很大的电压尖峰和 EMI。应该用肖特基、超快恢复管，或者同步整流。

软恢复和硬恢复有什么区别？

区别在 tb 段反向电流回落的快慢，用软度 S = tb / ta 表示。硬恢复 tb 短，电流被突然掐断，在回路寄生电感上产生 L·di/dt 的电压尖峰和振铃，容易过压，EMI 也大。软恢复电流平缓回落，尖峰小。电机驱动里 IGBT 的反并二极管就特别要求软恢复。

反向恢复带来的问题怎么解决？

第一选 Qrr 小的管子：低压用肖特基，高压用超快恢复或 SiC 肖特基。第二用同步整流代替二极管。第三适当减慢开关速度，di/dt 小了 IRM 就小，代价是开关损耗增加。第四在二极管两端加 RC 吸收抑制振铃，同时把功率回路布得紧凑，减小寄生电感。

肖特基二极管为什么没有反向恢复问题？

肖特基是金属-半导体结，靠多子导电，正向导通时不向对面注入少子，也就没有存储电荷。关断时只需要给结电容充电，时间是 ns 级，而且和正向电流基本无关。代价是漏电大、耐压低，下一页细讲。
