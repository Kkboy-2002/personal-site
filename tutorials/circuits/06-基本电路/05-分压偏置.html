基本电路 · 偏置

分压式偏置

三极管放大电路最常用的偏置：R1、R2 把基极电压钉住，Re 把发射极电流钉住。结果是 Q 点几乎不随 β 和温度变化。

Q 点 · β 与温度

拖 β 和温度，对比两种偏置的 Ic

分压电流远大于基极电流时，基极电压只由分压决定：

VB ≈ Vcc·R2 / (R1 + R2)　　IE ≈ (VB − 0.7) / Re　　Ic ≈ IE

式子里没有 β，所以换管子、β 变了，Ic 基本不变。温度升高时 Ic 想变大，Re 上的压降跟着变大，发射极电位抬高，Ube 被压小，Ib 自动减小，把 Ic 拉回来。这是直流电流负反馈。固定偏置只有一个基极电阻 RB，Ib 被定死，Ic = β·Ib，β 变多少 Ic 就变多少。

曲线 · 对 β 的敏感度

Ic 随 β 变化的两条线

精确一点，把 R1、R2 等效成戴维南电源 Vth、Rth，得到 Ic = β·(Vth − Ube) / (Rth + (1 + β)·Re)。只要 (1 + β)·Re 远大于 Rth，分母里的 β 和分子里的 β 就抵消了。工程上常取 R2 上的电流为 Ib 的 10 倍左右，VB 取 Vcc 的 1/5 ~ 1/3（经验值）。

旁路电容 Ce · 交流增益

Re 稳住了 Q 点，也吃掉了增益：Ce 把增益还回来

Re 对交流信号同样是负反馈，没有 Ce 时电压增益只有 Av ≈ −Rc / Re。Ce 对直流开路，不影响 Q 点；对交流短路，把发射极交流接地，增益恢复到 Av = −β·Rc / rbe。rbe ≈ rbb' + (1 + β)·26 mV / IE。

面试怎么答

常见追问

分压式偏置为什么能稳定 Q 点？

两点。一是 R1、R2 分压电流远大于 Ib，VB 由分压决定，基本不随管子变。二是 Re 引入直流电流负反馈：温度升高 → Ic 增大 → VE = IE·Re 升高 → Ube = VB − VE 减小 → Ib 减小 → Ic 回落。于是 IE ≈ (VB − 0.7) / Re，和 β 几乎无关。

Re 越大越稳定，为什么不无限加大？

Re 大了会吃掉电源电压：Uce = Vcc − Ic·(Rc + Re)，留给输出摆幅的空间变小。同时 Re 让交流增益降到约 Rc / Re。一般让 VE 取 1~2 V 或 Vcc 的 10%~20% 左右（经验值），交流增益交给 Ce 恢复。

发射极旁路电容 Ce 起什么作用？

隔直通交。直流下 Ce 开路，Re 照常稳定 Q 点；交流下 Ce 把发射极短路到地，消除 Re 的交流负反馈，增益从约 −Rc / Re 恢复到 −β·Rc / rbe。代价是增益对 β 和温度更敏感、线性变差，所以也常把 Re 拆成两段，只旁路其中一段。

分压电阻为什么不能取得太大？

因为要保证流过 R2 的电流远大于 Ib，一般取 5~10 倍以上（经验值），否则 VB 会被基极电流拉低，β 又重新出现在公式里。但也不能太小，太小会增加功耗，还会降低放大电路的输入电阻（输入电阻里并着 R1 // R2）。
