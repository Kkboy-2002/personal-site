通信接口 · 差分多主总线

CAN 总线

CAN 用一对差分线把汽车、工控里的几十个节点连在一起。它没有主机，谁都能发；几个节点同时发时，靠显性覆盖隐性的线与逻辑逐位比较 ID，ID 小的赢，而且赢的那一帧毫发无损。

显性 0 · 隐性 1

显性和隐性：为什么 0 能盖住 1

收发器发显性（逻辑 0）时，内部上管把 CAN_H 往上推到约 3.5 V，下管把 CAN_L 往下拉到约 1.5 V，差压约 2 V。发隐性（逻辑 1）时两个管子都关，收发器什么也不驱动，两根线经终端电阻连在一起，都停在约 2.5 V，差压约 0。

所以只要有一个节点发显性，总线就是显性，别的节点发隐性等于没说话。这和 I2C 开漏的线与是一回事：0 占优。接收器看差压：大于 0.9 V 判显性，小于 0.5 V 判隐性。

非破坏性逐位仲裁

三个节点同时发，谁赢

总线空闲时，想发的节点都可以开始发，从帧起始位 SOF 开始逐位往外送 ID，高位在前。每个节点边发边回读总线。发的是隐性 1、读回来却是显性 0，说明有人的 ID 更小，它就立刻停发，转为接收。发显性的节点根本察觉不到有过冲突，继续发自己的帧。

所以 ID 越小，前面的 0 越多，优先级越高。赢家的帧没被打断、不用重发，这叫非破坏性仲裁。输家等总线空闲后自动重发。

终端电阻 · 反射

两端各 120 Ω，少一个会怎样

双绞线的特性阻抗约 120 Ω。信号跑到线的尽头，如果端接电阻等于特性阻抗，能量被电阻吸收；如果开路，信号原样反射回来，和后面的信号叠加，形成振铃。所以总线两端各接一个 120 Ω，两个并联是 60 Ω。

终端电阻还有第二个作用：隐性时收发器不驱动，是终端电阻把 CAN_H、CAN_L 之间的电荷放掉，差压才回到 0。没有它，显性到隐性的边沿又慢又拖尾。

反射系数 Γ = (RT − Z0) / (RT + Z0)；RT = Z0 = 120 Ω 时 Γ = 0，开路时 Γ = +1

帧结构 · 简述

一个标准数据帧

CAN 不只是物理层，帧格式、仲裁、校验、应答、出错重发都由 CAN 控制器硬件完成。标准数据帧按顺序如下，扩展帧把 ID 扩到 29 位。

段位数作用
帧起始 SOF1一个显性位，所有节点以它的下降沿同步
仲裁段11 + 111 位 ID 加 RTR 位，数据帧 RTR 为显性，远程帧为隐性，所以同 ID 时数据帧优先
控制段6IDE、保留位 r0，加 4 位 DLC 表示数据字节数
数据段0 ~ 640 ~ 8 个字节；CAN FD 最多 64 字节，且数据段可以提速
CRC 段15 + 115 位 CRC 加 1 位隐性界定符
ACK 段1 + 1发送方在 ACK 槽发隐性，任何一个正确收到的节点把它改写成显性；再加 1 位界定符
帧结束 EOF77 个隐性位，之后至少 3 位帧间隔

从 SOF 到 CRC，发送方每连续发 5 个相同的位，就自动插入 1 个相反的位，叫位填充。因为 CAN 没有时钟线，接收方要靠边沿不停地重新同步，位填充保证边沿足够多。连续 6 个相同位出现在这一段里就是错误，节点会发错误帧。

面试怎么答

常见追问

什么是显性和隐性？为什么显性能覆盖隐性？

显性是逻辑 0，收发器主动把 CAN_H 推到约 3.5 V、CAN_L 拉到约 1.5 V，差压约 2 V。隐性是逻辑 1，收发器不驱动，两线都在约 2.5 V，差压约 0。一个是主动驱动、一个是放手不管，所以只要有人发显性总线就是显性，相当于线与。

CAN 仲裁是怎么做的？为什么叫非破坏性？

多个节点同时发，从 ID 最高位开始逐位比较，边发边回读。发隐性却读回显性的节点知道自己输了，马上停发转为接收。ID 越小越早出现 0，优先级越高。赢家的帧没有被打断，也不用重发，所以叫非破坏性。这也要求同一个 ID 只能由一个节点发送。

终端电阻为什么是 120 Ω？万用表量出来应该是多少？

因为双绞线特性阻抗约 120 Ω，端接相等才不反射。两端各一个，并联后断电量 CAN_H 与 CAN_L 之间应约 60 Ω。量到 120 Ω 说明少接了一个，量到 40 Ω 左右说明多接了一个。

CAN 的应答是怎么实现的？

发送方在 ACK 槽里发隐性，同时回读。只要总线上任何一个节点正确收到了这一帧，就在 ACK 槽发显性。发送方读到显性就知道至少有人收到了；读到隐性就报应答错误并自动重发。所以总线上只有一个节点时，它发的帧永远没有应答。

CAN 为什么抗干扰强？

物理层是差分加双绞线，外界干扰同时叠加到两根线上，差值基本不变。协议层有 CRC、位填充检查、格式检查和应答检查，发现错误就发错误帧，发送方自动重发。节点还有错误计数，错得太多会自己退到被动甚至离线，不会一直拖垮总线。
