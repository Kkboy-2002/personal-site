反射与阻抗匹配

信号沿走线传播时，每遇到一处阻抗变化就有一部分被弹回来。弹回来的波和原信号叠加，就是过冲和振铃。匹配电阻的作用是让这部分反射消失。

传输线判据

什么时候要把走线当传输线

看的不是时钟频率，而是上升沿。信号在 FR4 微带线上约 6 ps/mm（典型值），一个上升沿在走线上"铺开"的长度是 ℓ = tr / tpd。走线比这段长度短很多时，整条线上电压几乎同时变化，可以当普通导线；走线长到边沿的约 1/6 以上，线上不同位置的电压就不一样了，反射开始明显，要按传输线处理。

临界长度 ≈ (tr / tpd) / 6；1 ns 上升沿约 28 mm

反射系数 · 反弹图

反射怎么算：Γ 和来回弹

走线有特征阻抗 Z0，它是线上电压波和电流波之比，由线宽、介质厚度和介电常数决定，常用 50 Ω。波走到末端遇到负载 ZL，反射回来的比例是反射系数：

Γ = (ZL − Z0) / (ZL + Z0)

ZL = Z0 时 Γ = 0，没有反射；开路 Γ = +1，全反射同相叠加，电压翻倍；短路 Γ = −1。反射波回到源端，又按源端的 Γs 再反射一次，如此来回，每次到达接收端就叠加一个台阶，这就是反弹图算法。

两种匹配

源端串联匹配和末端并联匹配

源端串联匹配是让源端不再反射：Ro + Rs = Z0。线上先走一个半幅的波，到开路的接收端全反射，叠成全幅；反射波回到源端被吸收，一次就结束。末端并联匹配是让负载不反射：ZL = Z0，波到了就被吸收。

面试怎么答

常见追问

信号为什么会反射？怎么算？

传输线上电压波和电流波的比值固定为特征阻抗 Z0。到了负载处，负载要求的电压电流比是 ZL，两者不一致，多出来或不够的部分只能以反射波的形式回去。反射系数 Γ = (ZL − Z0)/(ZL + Z0)，开路 +1，短路 −1，匹配时为 0。

什么情况下需要考虑阻抗匹配？

看上升时间和走线长度，不看时钟频率。走线长度超过上升沿空间长度的约 1/6，也就是单程延时超过 tr/6 左右，就要按传输线处理。FR4 上 1 ns 的上升沿，临界长度大约 3 cm。

源端串联电阻怎么取值？

Rs = Z0 − Ro，Ro 是驱动器输出阻抗。50 Ω 线、驱动内阻十几到二十几欧时，Rs 常取 22~33 Ω。电阻要尽量靠近驱动器放。

源端匹配和末端匹配各适合什么场合？

源端匹配几乎不耗电，适合点对点、接收端在末端的连接，比如 SPI 时钟、单个存储器的地址线。末端匹配能在任意位置吸收反射，适合多负载总线或很高速的接口，代价是静态功耗和幅度下降。

示波器上看到时钟有过冲振铃，怎么判断是不是反射？

看振铃周期是否约等于走线往返延时的整数倍关系，比如开路负载时周期约 4·Td。在源端串一个 22~33 Ω 电阻，过冲明显变小就说明是反射。同时要排除探头接地线过长引起的假振铃。
