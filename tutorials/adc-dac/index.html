1. 概述：数字世界与模拟世界的桥梁

ADC（Analog-to-Digital Converter）

模数转换器：把连续电压值转换为离散的数字编码。四个基本步骤：

  1. 采样：按固定周期读取瞬时值
  2. 保持：将采样值维持到转换结束
  3. 量化：把幅度归入有限个电平
  4. 编码：输出二进制码

DAC（Digital-to-Analog Converter）

数模转换器：把数字编码转换为对应的模拟电压/电流。核心思想是按位加权求和：

Vout = VREF × (D / 2N)

其中 D 为 N 位数字量（0 ~ 2N−1），VREF 为参考电压。

2. 采样定理与混叠（Aliasing）

奈奎斯特采样定理：要无失真地恢复信号，采样频率 fs 必须大于信号最高频率 fin 的 2 倍。否则高频信号会"伪装"成低频信号，即混叠。

fs > 2 · fin（工程上常取 fs ≥ (2.5~4) · fin）

试一试：把采样频率调到低于信号频率的 2 倍，观察采样点如何"骗过"系统，重建出一个错误的低频波。

3. 量化：分辨率与量化误差

量化是把连续的幅度值近似为有限个离散电平的过程。N 位 ADC 把量程分为 2N 级，最小可分辨电压称为 1 LSB：

1 LSB = VREF / 2N      量化误差 ≤ ±0.5 LSB      SNRmax ≈ 6.02N + 1.76 dB

位数越高，台阶越细、量化误差越小。观察 1 bit 与 8 bit 的巨大差别。

4. DAC 原理与 R-2R 梯形网络仿真

DAC 的核心是按位加权：每一位二进制码控制一个开关，将该位的权重电压接入求和网络。最常见的实现是 R-2R 梯形电阻网络——只需两种阻值，每一位节点处的等效电阻都把它"对半分"，从而天然形成 1/2、1/4、1/8… 的权重。

常见 DAC 结构

  • 权电阻型：每位电阻按 2 的幂取值，位多时阻值范围过大，难以集成
  • R-2R 梯形：只用 R 和 2R，精度好，主流片内 DAC 结构
  • 电流舵型（Current Steering）：高速视频 DAC 常用
  • Σ-Δ（Sigma-Delta）型：1 bit + 噪声整形，音频 DAC 主流
  • PWM + 滤波：单片机无 DAC 时的简易替代方案

7. 关键性能参数

分辨率（Resolution）

输出码的位数 N。N 越大，可分辨的最小变化 1 LSB = VREF/2N 越小。例如 12 bit、3.3 V 量程时 1 LSB ≈ 0.8 mV。

采样率（Sample Rate）

每秒完成的转换次数（SPS / MSPS）。需满足奈奎斯特条件，并留出抗混叠滤波器的过渡带。

SNR 与 ENOB

信噪比 SNR 衡量噪声水平，理论上限 6.02N+1.76 dB。有效位数 ENOB = (SINAD−1.76)/6.02，实际芯片 ENOB 总小于标称位数。

线性度 INL / DNL

DNL：相邻码对应步进与理想 1 LSB 的偏差；INL：整条传输曲线与理想直线的偏差。DNL < −1 LSB 会出现"失码"。

建立时间与失调/增益误差

建立时间：DAC 输出稳定到指定精度所需时间；失调误差（曲线平移）与增益误差（斜率偏差）是两类系统性误差，可通过校准消除。

孔径时间与抖动

孔径抖动（Aperture Jitter）造成采样时刻不确定，对高频信号影响显著：SNRjitter = −20·log₁₀(2π·fin·tjitter)。
