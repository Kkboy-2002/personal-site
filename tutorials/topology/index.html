硬件拓扑图实验室

拓扑图只回答一件事:谁和谁连在一起、按什么结构连。它不关心型号、封装和走线位置。 下面每一节都可以拖动参数、看电流实时流动、看波形跟着变。

四个抽象层次,别搞混

L1框图 Block

只有功能方块和箭头。电源 → MCU → 传感器。粒度最粗,用来对齐需求。

L2 · 本页拓扑图 Topology

出现关键元件(开关管/电感/电容/节点),用标准电路符号画,但不带型号和参数。表达连接结构和能量、信号流向。

L3原理图 Schematic

拓扑 + 型号 + 阻容值 + 位号 + 网络名。可以直接导出 BOM 和网表。

L4PCB 布局布线

物理层:坐标、层叠、线宽、间距、回流路径。同一原理图能画出好坏差很远的 PCB。

本页使用的标准符号(GB/T 4728 / IEC)

一个拓扑对应无数张原理图。换个型号的 MOS、换个电感值,拓扑不变; 但把二极管换成同步管、把电感挪到另一条支路,拓扑就变了——这是判断"改动大不大"的标准。

Buck 降压拓扑 同步降压 DC-DC

开关把输入电压斩成方波,电感和电容把方波的平均值取出来。核心直觉: 电感不允许电流突变,所以它把断续的开关电流"抹平"成连续的输出电流。

VOUT 包络 iL 包络 目标 D·VIN

它到底怎么降压的

三条铁律撑起整个开关电源:电感电流不能突变、稳态下电感一个周期的净伏秒为零、 电容电压不能突变。

Q1 通 (时长 D·T): 电感两端 = VIN − VOUT 电流上升 Q1 断 (时长 (1−D)·T): 电感两端 = −VOUT 电流下降 伏秒平衡:(VIN−VOUT)·D·T = VOUT·(1−D)·T ⇒ VOUT = D · VIN

所以占空比就是电压比。反馈环路做的事只有一件:不停微调 D,把 VOUT 顶在设定值上。

跟着调,你会看到

  • 拖 D:VOUT 跟着线性变。这是最直接的因果。
  • 拖 L 变小:ΔiL 三角波变陡变高。ΔiL = (VIN−VOUT)·D / (L·fs)
  • 拖 fs 变高:ΔiL 和纹波都变小,但效率往下掉——开关损耗和驱动损耗跟 fs 成正比。 这就是"高频换体积、低频换效率"的取舍。
  • 拖 C 变小:VOUT 纹波变大。ΔVOUT ≈ ΔiL / (8·fs·C) (真实电路里常被电容 ESR 主导:ΔVOUT ≈ ΔiL·ESR)
  • 把 R 调很大(轻载):iL 谷值触底、出现断流,徽标变成 DCM。 此时 VOUT 不再只由 D 决定,会比 D·VIN 高——很多"轻载电压偏高"的现象就是这个。
DCM 边界:IOUT < ΔiL / 2。设计时如果要求全负载都 CCM, 就得在最轻负载下反推最小电感。

为什么效率能到 90%+

Buck 不"烧掉"压差,它把能量存进电感再倒出去。损耗只剩三块: MOS 导通损耗 (I²·Rds)、电感铜损 (I²·DCR)、开关与驱动损耗 (∝ fs)。 上面的效率是含这三块的粗略模型,数量级可信,具体值要看真实器件参数。

拓扑决定的 PCB 铁律

  • VIN→Q1→Q2→GND 是高 di/dt 热回路。输入电容必须紧贴这两个管子,回路面积越小越好, 这是 EMI 和 SW 尖峰的第一决定因素。
  • SW 节点是全板最脏的铜皮,能连通就行,面积尽量小,不要在它下面走敏感信号。
  • 反馈取样点要在负载端,否则线上的压降会被算进输出。
  • Q2 换成肖特基二极管就是"异步 Buck",省驱动但白扔 0.3~0.5V 的导通压降。

Boost 升压拓扑 升压 DC-DC

同样三个元件,只是换了个连接顺序:电感挪到输入端常通,开关放到低边。 电感先从输入"抽能量",开关一断,电感为了维持电流硬把电压顶起来,经二极管灌进输出电容。

升压的伏秒平衡

Q1 通: 电感两端 = VIN ,时长 D·T Q1 断: 电感两端 = VIN − VOUT ,时长 (1−D)·T VIN·D·T = (VOUT−VIN)·(1−D)·T ⇒ VOUT = VIN / (1 − D)

D=0.5 时输出翻倍,D=0.8 时是 5 倍。注意这是非线性的:D 越靠近 1,曲线越陡, 环路增益跟着变,所以 Boost 比 Buck 难稳。

和 Buck 完全相反的三个性质

  • 输入电流连续,输出电流断续。只有 Q1 断开时才有电流灌进输出电容, 所以输出电容的纹波电流很大,选电容要看 ripple current 额定值,不只是容量。
  • 输入到输出有一条直通路径(L + D1)。Boost 无法关断输出,也不能承受输出短路—— 短路电流直接从输入经电感二极管灌下去,没有任何开关能挡。
  • 存在右半平面零点,环路带宽被迫做得比 Buck 低,负载突变时的响应更肉。
把 D 拖到 0.9 以上试试:输出电压确实跟着 VIN/(1−D) 一路涨上去(这个模型是理想无损的), 但看一眼 iL 平均值——它按 IIN = IOUT/(1−D) 暴涨。 真实电路里,电感 DCR、MOS 导通电阻上的损耗按 I² 增长,所以输出根本涨不到理想值, 效率还会崩掉。实际设计里 D 一般不超过 0.75~0.8,要更高的升压比就换反激或者做两级。

同一组元件,三种拓扑

拓扑电感位置输出
Buck开关之后、串在输出路径D·VIN,同极性,降压

元件清单一模一样,只是连法不同——这就是"拓扑"最直白的含义。

DC-DC 拓扑选型全家福 从 Buck 到 LLC,一张图选对

上面两节只讲了 Buck 和 Boost,它们只是开关电源家族的两个成员。 真实选型先问一个问题:输入和输出要不要电气隔离(变压器隔开,常见于市电 AC-DC、安规要求、地环路隔离)。 这一问把拓扑劈成两大类,后面才看电压关系和功率。

非隔离家族(输入输出共地,占板级 DC-DC 的绝大多数)

Buck 降压 · 同步 / 异步

Vout = D · Vin

同步用低边 MOS 代替续流二极管,轻载效率更高;异步用肖特基,便宜。 这就是上面第②节画的电路,也是 90% 板级降压的选择。

Buck-Boost(反相)

Vout = −D/(1−D) · Vin

元件和 Buck 一样(MOS、电感、二极管),只是电感"开关后并到地", 输出反极性。用来产生负电源轨(−5V、−12V)。见第③节末尾的三拓扑对比表。

SEPIC / Ćuk

Vout = D/(1−D) · Vin(同相)

靠一个耦合电容(或耦合电感)实现升降压且输出同相。 用在输入电压会跨越输出的场合,如锂电池 3.0~4.2V 稳压到 3.3V。Ćuk 输入输出电流都连续,纹波小。

四开关 Buck-Boost

降压段 / 升降压段 / 升压段自动切换

同相、可升可降、效率高于 SEPIC。USB-PD、电池供电系统的主力拓扑, 一颗芯片覆盖 3~24V 宽输入。

电荷泵 Charge Pump

无电感,靠电容"搬运"电荷

倍压 / 负压 / 分数比(如 1.5×)。体积小、无磁性元件、EMI 低, 但只能供小电流(通常 < 200mA)。负压、LCD 偏压、栅极驱动常用。

多相 Buck(Multiphase)

N 相并联,纹波互抵

CPU/GPU 核心供电(VRM)。多相错相开关,分摊大电流(几十~几百 A)、 降低输出纹波和电容需求。

隔离家族(变压器隔开,AC-DC、安规、抗地环路)

反激 Flyback

变压器兼作储能电感(先存后放),结构最简单、元件最少。 < 75W 的充电器、适配器、家电辅助电源几乎全是它。容易做多路输出。

正激 Forward

变压器只传递能量不储能,开关导通时直接送能量到输出。 75~500W,比反激效率高、变压器利用率高,需要磁复位绕组。

推挽 / 半桥 / 全桥

变压器双向磁化,利用率高。半桥最常用(平衡、变压器不会偏磁饱和), 全桥用于 > 500W 大功率。服务器、通信电源的主力。

LLC 谐振

靠谐振实现软开关(ZVS/ZCS),开关损耗极低,效率可达 96%+。 高端电源、服务器、快充。控制复杂,是半桥的谐振升级版。

拓扑读法

从右往左看:R1/R2 把输出分压给 FB,误差放大器拿 FB 跟内部基准 Vref 比, 差多少就把调整管的阻值调多少。这是一个纯粹的负反馈闭环。

VOUT = Vref · (1 + R1/R2) Pd = (VIN − VOUT) · IOUT ← 全部是热 η = VOUT / VIN ← 与负载无关,只看电压比 Tj = Tambient + Pd · θja

两个必须记住的坑

  • Dropout 电压。调整管不是理想开关,它自己需要一点压差才能工作。 VIN 掉到 VOUT+Vdo 以下时,输出就直接跟着输入抖。拖 VIN 到 3.4V 以下看效果。
  • 发热与 θja。Pd 不变,换个封装(θja 从 150 降到 25)结温能差 100 °C 以上。 SOT-23 的 LDO 掉 3V 拉 300mA 基本必然过温。

那为什么还要用 LDO

  • 干净。没有开关动作,输出噪声可以做到几十 µV,PSRR 高。ADC 基准、PLL、射频、 晶振都爱用它。
  • 简单便宜。两颗电容就能工作,不用电感,不用管环路和布局。
  • 响应快。环路带宽可以做得比开关电源高得多。
工程上最常见的组合拳:Buck 先把 12V 高效降到 3.6V,再用 LDO 出 3.3V 模拟电源。 压差只剩 0.3V,发热很小,又拿到了 LDO 的干净输出。这就是下面"电源树"那一节要解决的问题。

二阶 LC 的三个数

f0 = 1 / (2π·√(L·C)) 谐振频率 Q = R · √(C/L) 品质因数(R 是负载) 斜率 = −40 dB/十倍频 超过 f0 之后

设计口诀:把 f0 放在 fs 的 1/10 以下。这样 fs 处至少能拿到 40 dB(100 倍)衰减。 右上角的 fs/f0 倍数就是在盯这件事。

调一调,三个反直觉的现象

  • ESR 会把滚降斜率从 −40 掰回 −20 dB/十倍频。把 ESR 从 0 拖到 200 mΩ, 看曲线高频段明显变缓。拐点在 f = 1/(2π·C·ESR)——超过它以后, 电容的容抗已经比自己的 ESR 还小,滤波能力被 ESR 卡死。 这时候再加容量几乎没用,必须换低 ESR 的电容或者并联多颗分摊。 默认参数下这个拐点就落在 fs 附近,所以真实纹波常常是 ΔVOUT ≈ ΔiL × ESR 而不是理论的 1/(8fsC)。
  • 轻载时 Q 会变高。把 R 拖大,f0 处冒出一个尖峰。这个峰会放大落在附近的负载扰动, 也是环路补偿要处理的对象。
  • 容量翻倍只降 6 dB,频率翻倍降 12 dB。二阶滤波器里,提高 fs 比堆电容划算得多—— 代价是开关损耗,回到 Buck 那一节的取舍。

π 型 / 两级的真正用途

勾上"两级 LC":高频段斜率从 −40 变成 −80 dB/十倍频。代价是多一个谐振点、 环路更难稳、体积更大。所以两级一般只用在:

  • 给 ADC、射频、PLL 的模拟电源做二次滤波(常见做法是第二级用小电感或磁珠 + MLCC)
  • 需要过 EMI 传导测试,把开关谐波压到限值以下
选电容的拓扑经验:大容量电解/钽负责低频储能,小容量 MLCC 负责高频去耦, 并联使用。因为 MLCC 有 ESL(寄生电感),超过自谐振点后它自己就变成电感了—— 所以去耦电容一定要靠近芯片引脚,那段走线的电感比电容本身的 ESL 还大。

运放基本电路 同一个三角形,八种接法

运放本身只是一个增益极大(10⁵ 以上)的差分放大器,它自己什么都干不了。 真正决定功能的是外面的反馈网络怎么接:换一套阻容的连法,就从放大器变成加法器、积分器或者比较器。 这是"拓扑决定功能"最经典的例子。点下面的按钮切换。

先记住两条"虚"

虚短:负反馈成立时 V− = V+ (增益无穷大,输出有限 ⇒ 差值只能是零) 虚断:两个输入端不取电流 (输入阻抗无穷大 ⇒ 电流只能走外部支路) 饱和:|VOUT| 最多到 VCC − 1.2 V 左右,再大就削顶

下面每一种电路都按同一套三步推:① 虚短定出 − 端电压 → ② 算出输入支路的电流 → ③ 虚断说明这股电流只能钻进反馈支路,于是反馈元件两端的压降就是输出。

反相放大器

① 虚短:+ 端接地 ⇒ V− = V+ = 0,称"虚地" ② R1 两端是 VIN 和 0 ⇒ i = VIN / R1 ③ 虚断:i 进不了运放,只能全部流过 Rf VOUT = 0 − i·Rf = −(Rf / R1) · VIN
  • 增益可以小于 1(Rf < R1),这是同相放大做不到的。
  • 输入阻抗 = R1,信号源要驱动它。R1 取大则噪声和失调变大,这是它的主要缺点。
  • − 端是"虚地":电压为零但并不真的接地。PCB 上这个节点要短、要小,它对寄生电容最敏感。
  • 把 Rf 拖到 1 MΩ:增益 100,输出立刻撞到 ±Vsat 削顶——运放不会"放大到无穷",只会饱和。

同相放大器

① 虚断:VIN 直接进 + 端,不取电流 ⇒ V+ = VIN ② 虚短:V− = V+ = VIN ③ − 端是 Rf、R1 对 VOUT 的分压点:VIN = VOUT · R1/(R1+Rf) VOUT = (1 + Rf / R1) · VIN
  • 增益 ≥ 1,永远不小于 1(R1 → ∞ 就退化成跟随器)。
  • 输入阻抗极高:信号直接进运放输入端,不取电流。高阻传感器优先用它。
  • 增益越大,闭环带宽越窄:GBW 固定,增益 100 时带宽只剩 GBW/100。

电压跟随器(缓冲器)

① 输出直接短接回 − 端 ⇒ V− = VOUT ② 虚短:V− = V+ = VIN VOUT = VIN,增益 = 1(同相放大取 Rf = 0、R1 = ∞ 的特例)
  • 不放大电压,放大的是电流驱动能力:输入阻抗极高,输出阻抗接近零。
  • 典型用法:高阻传感器 → 跟随器 → ADC。这就是 SAR ADC 那一节说的"采样瞬间抽电荷"的解药。
  • 把基准电压、分压点"复制"一份去驱动负载,而不影响原来的节点。
  • 100% 负反馈,是最容易振荡的接法:选运放时要看它是不是 "unity-gain stable"。

反相加法器(求和放大器)

① 虚短:+ 端接地 ⇒ − 端仍是虚地 0 V ② 每路电阻的另一端都被钉在 0 V,所以三路电流互不干扰: i = V1/R1 + V2/R2 + V3/R3 ③ 虚断:三路电流在 − 端汇合后只能一起流过 Rf VOUT = −Rf · (V1/R1 + V2/R2 + V3/R3)
  • 每一路的权重是 Rf/Ri,各自独立、互不影响——因为虚地把各输入隔开了。
  • 图里 V1 是正弦,V2 是直流偏置,V3 是 3 倍频正弦。看输出:直流把整个波形抬起来,3 倍频叠成小波纹。
  • 用途:音频混音、给信号加偏置(把 ±1V 变成 0~3.3V 送进单电源 ADC)、R-2R DAC 的核心。
  • 想要不反相,后面再串一级增益 −1 的反相器,或者用同相加法(但那种各路权重会互相牵连)。

差分放大器(减法器)

① 虚断:V2 经 R2、R3 分压后进 + 端,分压点不被取电流 V+ = V2 · R3/(R2+R3) ② 虚短:V− = V+ ③ 虚断:R1 上的电流只能全部流过 Rf (V1 − V−)/R1 = (V− − VOUT)/Rf 取 R2 = R1、R3 = Rf(图中已固定)化简: VOUT = (Rf / R1) · (V2 − V1)
  • 名字容易混:运放芯片内部本身就是个差分放大器(开环、增益 10⁵、不可控);这里说的是外面用四个电阻搭出的差分放大电路,增益由电阻定,做的是减法运算。
  • 只放大两端的差,两端共有的部分(共模)被抵消。测电流采样电阻两端的压差、抑制地线噪声都靠它。
  • 四个电阻必须精确匹配,失配 0.1% 就让共模抑制比(CMRR)掉到 60 dB 左右。用集成的电阻阵列或者仪表放大器。
  • 两个输入阻抗不一样(V1 端看到 R1,V2 端看到 R2+R3)而且都不高——这是它的先天缺陷,仪表放大器就是在前面加两个跟随器来解决。

积分器

反馈支路的 Rf 换成电容 C ① 虚短:− 端仍是虚地 0 V ⇒ ② i = VIN / R1 ③ 虚断:i 只能给 C 充电,而 C 上的电压 = 0 − VOUT VOUT = −(1 / R1·C) · ∫ VIN dt 方波输入 → 三角波输出,斜率 = VIN / (R1·C)
  • 时间常数 τ = R1·C。τ 越小,三角波越陡、幅度越大,很快撞饱和。拖 C 或 f 试试。
  • 它就是一个截止频率极低的一阶低通:高于 1/(2πR1C) 的成分以 −20 dB/十倍频衰减。
  • 用途:三角波发生器、PID 里的 I 项、Σ-Δ ADC 的调制器前端。

为什么反馈电容必须并联 Rf(默认已开启,取消勾选对比)

理想积分器的增益: |H(f)| = 1 / (2πf·R1·C) ⇒ f → 0 时增益 → ∞ 运放不是理想的,输入端存在: 失调电压 Vos (几 mV) 偏置电流 Ib (nA ~ pA) 这些直流误差被"无穷大的直流增益"积分: dVOUT/dt = Vos / (R1·C) 单向漂移,几秒内撞到 ±Vsat 并联 Rf 后,反馈阻抗 Zf = Rf ‖ (1/sC): H(s) = −(Rf/R1) / (1 + s·Rf·C) 直流增益被封顶在 −Rf/R1(有限值),漂移消失 拐点 fc = 1 / (2π·Rf·C),高于 fc 才是"真积分"
  • 低频段(f ≪ fc):退化成一个增益 −Rf/R1 的普通反相放大器——Rf 把直流和失调"钳住"了。
  • 高频段(f ≫ fc):电容阻抗远小于 Rf,Rf 不起作用,纯积分。
  • 取值是权衡:Rf 太小 → fc 偏高,积分频段变窄;Rf 太大 → 直流增益 Rf/R1 又太大,漂移回来了。 经验:fc 放在最低有用信号频率的 1/10 以下,同时 Rf/R1 ≤ 100 左右。 典型 R1=10k、Rf=1M、C=10nF → fc ≈ 16 Hz。
  • 勾选"模拟 Vos 直流漂移":输入里叠加一个 5 mV 失调,取消 Rf 看输出以固定斜率单向爬向饱和; 勾回 Rf,输出稳定在 Vos·(Rf/R1) 的小值上。这就是这颗电阻存在的全部意义。
  • 电容旁边除了电阻,还可能是一个开关(勾选"并联复位开关"):周期性把 C 短路放电、输出清零。 双积分 ADC、峰值保持、脉冲积分电路都是这么做的。
  • 微分器的对偶问题:它把 C 放在输入侧,高频增益 → ∞ 会放大噪声, 所以实际电路在 C 前串小电阻、Rf 上并小电容,变成"带限微分器"——同样是给无穷大增益封顶。

微分器

输入支路的 R1 换成电容 C ① 虚短:− 端仍是虚地 0 V ⇒ C 两端电压就是 VIN ② 电容电流只看电压变化率:i = C · dVIN/dt ③ 虚断:i 全部流过 Rf VOUT = −Rf·C · dVIN/dt 三角波输入 → 方波输出,幅度 = Rf·C · 斜率
  • 增益随频率线性上升,高频噪声被无限放大——这是它几乎不单独使用的原因。
  • 实际会在 C 前串一个小电阻、Rf 上并一个小电容,把高频增益压住,变成"带限微分器"。
  • 输入阻抗 = 1/(2πfC),频率越高越低,信号源会被拉垮。
  • 用途:边沿检测、PID 里的 D 项、把三角波变方波。

迟滞比较器(施密特触发器)

反馈接到 + 端 ⇒ 正反馈,虚短不成立(差值被越推越大),只剩虚断可用 ① 输出只有两态:+Vsat 或 −Vsat ② 虚断:+ 端不取电流,R1、Rf 就是 VOUT 到地的纯分压器 V+ = VOUT · R1/(R1+Rf) = ±VT ③ 翻转条件是 VIN 追过 V+: VIN > +VT ⇒ VOUT = −Vsat;VIN < −VT ⇒ VOUT = +Vsat
  • 普通比较器在阈值附近遇到一点噪声就来回抖;迟滞把上下阈值分开,翻转之后要反向越过另一个阈值才能翻回来。
  • 把 R1 拖大、Rf 拖小,阈值张开;把输入幅度拖到阈值以下,输出就再也不翻转了。
  • 这一节唯一的正反馈电路。和前面所有负反馈电路的区别只是反馈接到了 + 端,拓扑差一根线,行为完全不同。
  • 用途:开关信号整形、按键去抖、加一个 RC 就是张弛振荡器。
怎么快速认出一张运放电路:先找反馈从输出接回哪个输入端——接 − 端是负反馈(放大/滤波/运算),接 + 端是正反馈(比较/振荡);再看反馈支路和输入支路是电阻还是电容——电阻是比例,电容是积分/微分。

运放不理想的四个参数(上面八种电路都是"理想运放",真实芯片差在哪)

前面所有推导都用了"增益无穷大、输入不取电流、速度无限快"三个假设。 真实运放这四条都不成立,于是有了四个必须查手册的参数。它们不改拓扑,但决定拓扑能不能用、用到什么程度。

四个参数怎么影响选型

  • 放大直流/缓变信号(称重、温度):Vos 和温漂是主角,选"零漂移/自稳零"运放,或者用下面仪表放大器把 Vos 的影响压下去。
  • 放大交流快信号(音频、视频):GBW 和 SR 是主角,带宽要留 10 倍以上余量。
  • 高阻源(pH 电极、光电二极管):Ib 是主角,选 CMOS/JFET 输入(fA 级),否则偏置电流在源阻抗上的压降比信号还大。
  • 积分器:四个参数全中——Vos/Ib 造成漂移(所以并 Rf)、GBW 限制高频、SR 限制大幅值。它是最"挑剔"的接法。
  • 手册上还有两个常看的:CMRR(共模抑制,差分/仪表放大器的命根子)和是否 rail-to-rail(低压单电源系统必问)。

实战中另外三种常见接法(八种基本接法的组合与变形)

仪表放大器 In-Amp(三运放)

Vout = (1 + 2R/Rg) · (Rf/R1) · (V2 − V1)
  • 上面差分放大器的两个先天缺陷(输入阻抗低且不平衡、CMRR 靠电阻匹配)在这里都被解决: 第一级两个同相端输入阻抗极高且对称,共模增益只有 1。
  • 增益只靠一颗 Rg 调(外接一个电阻即可),其余电阻厂内激光修调,CMRR 可达 100 dB 以上。
  • 用途:电桥传感器(应变片、称重、压力)、心电图 ECG、热电偶——所有"小差模骑在大共模上"的场合。
  • 实际工程直接买集成仪表放大器(AD620/INA128/INA826),比自搭三运放便宜且指标更好。

跨阻放大器 TIA(电流 → 电压)

  • 光电二极管输出的是电流(nA~mA,正比于光强),不是电压。TIA 把它变成电压:虚地让二极管两端压差恒为 0,电流全部流过 Rf。
  • Cf 是稳定性补偿:二极管的结电容 + 运放输入电容和 Rf 构成极点,不加 Cf 会振荡。Cf 与 Rf 并联把这个极点压住,代价是带宽 f ≈ 1/(2πRfCf)。
  • 这就是"积分器拓扑"的近亲:反馈同样是 R∥C,只是这里要的是直流增益 Rf,积分行为反而是需要 Cf 小心控制的副作用。
  • 用途:光模块接收端、激光雷达、脉搏血氧、烟雾探测器。选运放第一看 Ib(fA 级),第二看 GBW。

Sallen-Key 二阶有源滤波

  • 用运放(这里接成跟随器)把两级 RC "顶"起来,得到真正的二阶响应:−40 dB/十倍频,且两级之间不互相拖累——无源两级 RC 做不到(Q 永远 ≤ 0.5)。
  • C1 接到输出而不是地,这是它和普通两级 RC 的拓扑差别,正是这个正反馈路径把 Q 提了上来。
  • 用途:ADC 前的抗混叠滤波、音频分频、传感器信号调理。要更陡就 cascading 多级,或用多重反馈(MFB)变体。
  • 和 LC 滤波那一节对照:LC 靠储能元件、能过大电流;Sallen-Key 靠运放、只适合小信号,但不需要电感、频率做得很低。

  1. 采样。S1 闭合,Chold 充到 VIN。这一步要花时间,因为它是个 RC 充电。
  2. 保持。S1 断开,Chold 上的电压被冻结,后面所有比较都针对这个冻结值。
  3. N 次比较。从最高位开始,DAC 先输出半量程 VREF/2,比较器问一句 "被测电压比这个大吗?" 大→该位记 1 并保留,小→该位记 0 丢掉。 然后拿次高位继续,每次把区间对半砍。
1 LSB = VREF / 2^N 量化误差 ≤ ±0.5 LSB 转换时间 = (N + 1) / fclk ← 采样占 1 个时钟 最高采样率 = fclk / (N + 1)

看图里的灰带:每一步高度都缩一半,N 步之后缩到 1 个 LSB。这就是"逐次逼近"这个名字的来历—— 它是二分查找的硬件实现。

拓扑上的三个致命细节

  • VREF 就是标尺。所有结果都是 VIN/VREF 的比值。VREF 抖 1 mV,读数就跟着错。 所以 VREF 必须低噪声、低阻、就近去耦——这正是上一节 LDO + 二次 LC 滤波的战场。 拖动 VREF 你会看到同一个 VIN 读出完全不同的码。
  • 采样瞬间要抽电荷。S1 一闭合,Chold 要从信号源身上瞬间抽走一坨电荷。 如果前面接的是高阻传感器,电压会被拉塌,读数偏低。解决办法:前面加运放缓冲, 或者留够采样时间 + 加 RC。这也是"我的 ADC 读数不准"最常见的原因。
  • N 大不等于准。12 位 ADC 在噪声 3 mV 的板子上,后面 3 位纯粹是噪声。 有效位数由布局、地、参考源决定,不由数据手册上的位数决定。
采样定理:输入频率必须低于 fclk/(N+1)/2,否则高频成分会折叠到低频伪装成信号 (aliasing),而且软件里无法分辨。唯一的解决办法是在 ADC 前面加模拟抗混叠滤波器—— 又回到 LC/RC 滤波那一节。

怎么算

从末端往上,逐级推: 开关电源: IIN = (VOUT · IOUT) / (η · VIN) 线性 LDO: IIN = IOUT (电流不变,压差变热) Pd = (VIN − VOUT) · IOUT 某一级的 IOUT = 挂在它上面的负载 + 它下游所有子级的 IIN

为什么要分级,不直接 12V → 1.8V

  • 占空比太极端。12V 到 1.8V 需要 D=0.15,开关导通时间被压得很短, 高频下精度和效率都难看。分两级各自工作在舒服的占空比区间。
  • 模拟和数字要隔开。数字域的开关噪声会顺着电源灌进 ADC。 所以给模拟域单独拉一路 LDO(图里的 3.3V_A),而不是从数字 3.3V 直接分。
  • 就近降压。大电流的低压轨要尽量靠近负载,否则铜皮上的 IR 压降吃掉余量。

画电源树时顺手要定的几件事

  • 电流预算留 30% 余量。手册上的 typ 值不是最坏情况。
  • 上电顺序。很多 FPGA/SoC 要求内核先上、IO 后上,顺序错了会有大电流甚至锁死。 树上要标出 EN 引脚是被谁的 PG(Power Good)拉起来的。
  • 浪涌电流。所有电容一起充电的瞬间电流可能是稳态的好几倍,决定保险丝和上游选型。
  • 标出每一级的地。模拟地和数字地在哪一点单点连接,这条信息属于电源树,不属于原理图。

通信总线拓扑 互连结构

同样是"几个芯片连起来",物理结构不同,能不能工作的结论就完全不同。 这类拓扑接错不会"性能差一点",而是直接通信失败。

I²C · 总线型 Bus

开漏输出 + 一对上拉, 所有器件挂同一对线,靠 7 位地址区分。只在总线上拉一次,每个从机再加上拉是常见错误。 总线电容(线长 + 器件数)决定上升时间,超了就必须降速或减小上拉阻值。

SPI · 星形 Star

时钟和数据三根共享, 片选一人一根——所以从机越多,主机 IO 越吃紧。没有地址、没有应答,速度可以做到几十 MHz。 另一种接法是菊花链:数据从上一个从机的输出串到下一个的输入,只用一根 CS, 代价是必须整链一起刷。

CAN / RS-485 · 线型 + 两端终端

必须是一条线,两端各一个 120Ω。 拉成星形、或者中间挂一条长支线,反射就会把差分眼图糊掉。中间节点的支线必须短 (几厘米级)。只装一个终端电阻或者装了三个,都是现场最常见的故障。

DDR3/4 · fly-by 菊花链

走线依次经过每颗颗粒,末端接 VTT 终端。代价是每颗颗粒收到时钟的时刻不同,所以 DDR3 引入了 write leveling 在控制器里补偿相位差。DDR2 时代用的是 T 型(分支点到各颗等长), 频率上去之后分支的残端反射受不了,才换成 fly-by。

拓扑典型总线为什么必须这样
总线型I²C、SMBus、1-Wire 开漏 + 一对上拉,谁都可以把线拉低。速度低,所以不用管反射,只管总线电容。
星形SPI(独立 CS)、并行总线 点对点性质最好,时序最容易满足;代价是主机 IO 数量随从机线性增长。
菊花链SPI 链、CAN、RS-485、LED 灯串 一条线串下去,布线最省。差分高速场合必须两端匹配,支线要短。
fly-byDDR3/4 的 CLK/ADDR/CMD 用相位补偿换掉分支残端,频率才能上去。
树形以太网交换、USB Hub、时钟分配 每一级都是缓冲/交换,把长距离拆成多段点对点。
判断一个互连拓扑对不对,只问三个问题: ① 谁驱动这根线,会不会有两个驱动源同时上(冲突)? ② 空闲时电平由谁决定(上拉/下拉/失效偏置)? ③ 信号边沿够快时,这根线是不是传输线——如果是,阻抗和终端就必须算。
