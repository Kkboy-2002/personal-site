C 内存布局模拟同一份程序逐行执行：递归把栈帧一层层往下压，malloc 让堆往上长、free 即消失，全局变量与 static 从程序启动活到结束。左侧单步，右侧看内存怎么动。

栈 ▼堆 ▲静态区

内存图从上到下即从高地址到低地址：栈从 0x10000 向下增长（每调一层函数压入一个新帧，返回即销毁）；堆从 0x8000 向上增长（malloc 开块，free 归还）；静态区在最下面装全局变量、static 局部变量和字符串常量。地址为模拟值——真实程序里地址每次运行都会随机变化，但三个区域的相对位置和增长方向与真实的 64 位 Linux 进程一致。代码可编辑：把 free(buf) 删掉，运行结束后堆上的块还留着，那就是内存泄漏的样子。
