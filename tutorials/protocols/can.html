1总线拓扑:所有节点挂在同一对双绞线上

CAN 是多主(Multi-Master)广播式总线:所有 ECU 节点并联在 CAN_H / CAN_L 双绞线上, 两端各接 120Ω 终端电阻防止信号反射。任何节点发送的报文,所有节点都能收到, 再由各节点自行「验收滤波」决定要不要处理。点击播放,看一条报文如何广播。

提示:报文 ID=0x100(发动机转速),仪表盘和变速箱需要它,车窗控制器不需要。
多主结构
没有主机/从机之分,任何节点都可以主动发起发送,靠仲裁解决冲突。
广播 + 验收滤波
报文不写目的地址,只写「内容标识 ID」。节点按 ID 过滤,决定接收或忽略。
双绞线 + 终端电阻
双绞抵消电磁干扰,120Ω 电阻吸收信号能量,防止末端反射造成波形畸变。

2物理层:用「电压差」表示 0 和 1

CAN 不看单根线的电平,而看 CAN_H 与 CAN_L 的电压差: 差值约 2V 时为显性电平(逻辑 0), 差值约 0V 时为隐性电平(逻辑 1)。 显性能「压过」隐性——这正是后面仲裁机制的物理基础。共模干扰同时影响两根线,差值不变,所以抗干扰极强。

显性 Dominant = 0(H/L 分开,差压≈2V) 隐性 Recessive = 1(H/L 重合,差压≈0V)
关键规则:总线上只要有一个节点发显性(0),总线就呈显性——「线与」逻辑。

4核心机制:非破坏性逐位仲裁(CSMA/CA)

多个节点同时开始发送怎么办?CAN 的答案优雅至极:各节点一边发 ID 一边回读总线电平。 由于显性(0)会覆盖隐性(1),当某节点发出 1 却读回 0,说明有更高优先级的节点在发送, 它立刻退出转为接收——报文毫发无损,ID 数值越小优先级越高。点「下一位」逐位观察三个节点的竞争。

6错误处理:总线的自愈能力

CAN 内建 5 种错误检测。任一节点发现错误立即发送错误帧(6 个连续显性位,故意破坏当前报文), 迫使发送方自动重发。每个节点还有错误计数器,错误太多的节点会自动「降级隔离」,防止一个坏节点拖垮整条总线。

位错误
发送方回读总线,发现电平与自己发的不一致(仲裁段与 ACK 段除外)。
填充错误
规则:连续 5 个同电平后必须插入 1 个反相位;收到 6 个连续同电平即报错。
CRC 错误
接收方按同样多项式计算校验和,与帧内 CRC 字段不符则报错。
格式错误
固定格式字段(CRC 界定符、ACK 界定符、EOF)出现了非法电平。
ACK 错误
发送方在 ACK 槽读不到任何显性位——没有任何节点正确收到这条报文。
故障隔离
错误计数 >127 转「被动错误」态,>255 直接「总线关闭」自我下线。
一句话总结:CAN = 广播总线 + 线与电平 + ID 仲裁定优先级 + CRC/ACK 保可靠 + 错误计数器保自愈。
