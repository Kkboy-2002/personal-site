UART 异步串口

一切串口的逻辑内核:起始位对表、约定波特率、位中间采样。先学它,后面全通。

点对点全双工无时钟线入门必学
▶ 进入学习:全双工收发 / 帧格式 / 采样动画

RS-232 串行接口

UART 时序 + ±12V 负逻辑电平 + DB9 接口。经典点对点串口,Console 口至今在用。

点对点±12V 负逻辑≤15mDB9
▶ 进入学习:电平对比 / DB9 引脚 / RTS·CTS 流控动画

RS-485 差分总线

把 UART 字节流搬上差分线:千米级距离、一主多从轮询,Modbus 的物理载体。

总线型差分~1200m半双工工控主力
▶ 进入学习:主从轮询 / 差分电平 / DE·RE 换向动画

CAN 控制器局域网

多主总线的巅峰设计:显性压隐性、逐位仲裁定优先级、CRC+ACK+错误计数保可靠。

多主逐位仲裁差分汽车/工业高可靠
▶ 进入学习:广播滤波 / 帧结构 / 逐位仲裁动画

SPI 同步串行

主机摇时钟、片选点名,两个移位寄存器围成环交换数据。板级高速通信首选。

一主多从全双工数十 MHz四线+CS
▶ 进入学习:片选切换 / 移位交换 / CPOL·CPHA 动画

I²C 两线总线

SDA+SCL 两根线,开漏线与,7 位地址寻址,逐字节 ACK。省引脚挂满一板外设。

两线地址寻址开漏上拉多主可仲裁
▶ 进入学习:地址寻址 / START·STOP 时序波形动画

路建议学习路线

① 先学 UART,掌握「异步 + 起始位 + 波特率」的底层逻辑;
② 再看 RS-232 / RS-485——它们只是给 UART 换了「电平外衣」,分别解决点对点和长距离组网;
③ 然后看 SPI / I²C,理解「有时钟线」的同步通信如何免去波特率约定,以及两种截然不同的点名方式;
④ 最后攻 CAN——它把差分、仲裁、校验、容错整合到极致,是前面所有概念的集大成者。
