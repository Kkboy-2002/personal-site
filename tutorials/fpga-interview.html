第 1 章

位宽 × 深度 = 容量：所有存储器都在说同一句话

大白话。把存储器想成一排储物柜。位宽是每个柜子能放几颗珠子，也就是一次存进去或取出来多少 bit。深度是有多少个柜子，也就是有多少个地址。容量就是柜子数 × 每柜珠子数。柜子要编号，编号用二进制，所以 地址线根数 = log2(深度)。

把地址线拉到 28 根、位宽选 16，行数变成 2 亿 6 千万行，这就是一颗 4Gb 的 DDR3 颗粒。原理一模一样，只是柜子多得画不下。

同一个道理套在 FPGA 里的 BRAM 上

Xilinx 一块 BRAM 是 36Kb，面积固定。你可以把它配成「很宽很浅」，也可以配成「很窄很深」，乘积不变。面试常问「一块 BRAM 能存多少」，答案要带上「看你配成什么形状」。

动手试：同一块 36Kb BRAM 的七种形状
一句话。位宽是一次搬多少 bit，深度是有多少个地址，容量是两者相乘，地址线根数是深度的 log2。FIFO、BRAM、DDR 都是这一句。FIFO 的「深度」就是它能暂存多少个数据，「位宽」就是每个数据几位。
第 2 章

DDR 到底多少位宽、多深

大白话。DDR 的位宽和深度写在型号里。MT41K256M16 读成「256M 深 × 16 位宽」：有 256M（2 亿 6 千万）个地址，每个地址存 16 bit。相乘就是 4096Mb = 4Gb。注意小 b 是 bit，大 B 是字节，4Gb = 512MB，面试里说错单位很扣分。

深度是怎么凑出来的：楼 → 走廊 → 房间

DDR 内部不是一排平铺的柜子，而是分成 bank（几栋楼）、row（每栋楼几条走廊）、column（每条走廊几个房间）。地址位数三者相加，深度 = 2 的这个次方。读写前要先「打开一条走廊」，叫激活一行；走廊里的房间可以连续访问，所以同一行内读写快，换行慢。

板子上的位宽：几颗并排就是几倍宽

一颗 x16 只有 16 根数据线。想要 32 位或 64 位总线，就把几颗并排接，地址和命令线共用，数据线各管一段。这就是「拼位宽」。想要更大容量但不加宽，就再放一组颗粒共用数据线、用不同片选，这叫加一个 rank，是「拼深度」。

常见组合：FPGA 开发板 2 颗 x16 = 32 位；电脑内存条 8 颗 x8 = 64 位，再加 1 颗 x8 做 ECC 就是 72 位。

带宽和「为什么 MIG 用户接口是 128 位」

DDR 的 D 就是 Double：时钟上升沿和下降沿各传一次，所以 DDR3-1600 的时钟只有 800 MHz，每秒传 1600M 次。带宽 = 传输速率 × 位宽。每次读写固定连传 8 拍，叫 BL8，一次搬 8 × 位宽 bit。FPGA 里用户逻辑跑不了那么快，Xilinx MIG 让用户时钟是 DDR 时钟的 1/4，为了不丢吞吐，把用户接口位宽乘 8（双沿 × 4 倍频）。

一句话。位宽看颗粒是 x 几、板上并了几颗；深度看 bank 位 + 行位 + 列位加起来是 2 的几次方；容量是两者相乘；带宽等于速率乘位宽；一次 burst 搬 8 拍，所以 MIG 用户接口是 DQ 位宽的 8 倍。

第 3 章

  
异步时钟为什么会出错：触发器是一台快门相机


  
大白话。触发器在时钟沿「按快门」。快门有一段曝光时间：沿之前叫 建立时间 Tsu，沿之后叫 保持时间 Th。曝光期间被拍的信号必须一动不动，动了照片就是糊的，输出在 0 和 1 之间晃一会儿才落定，这就是 亚稳态。同步信号跟时钟有约定，永远在曝光外面变化。异步信号不知道快门什么时候按，早晚会撞进曝光窗口。


  

  
两级触发器：糊了别急着用，等一拍再拍一次

  
第一级拍糊了没关系，只要它在一个周期内落定，第二级拍到的就是干净的 0 或 1。这叫两级同步器。它只降低出错概率，不能归零。「多久出一次错」叫 MTBF，每多加一级，MTBF 指数级变长。


  

  

    
动手试：感受一下 MTBF 为什么是「指数级」

    

      
      
      
    

    

    
MTBF = e^(t_r / τ) / (T0 · f_clk · f_data)
t_r = 留给亚稳态落定的时间 ≈ 级数 × 周期 − 走线和建立时间
这里用的 τ、T0 是示意常数，不是真实器件值，只看趋势：
级数每 +1，t_r 多一个周期，MTBF 乘一个巨大的倍数；时钟越快，每级能给的 t_r 越少。

  


  
一句话。异步信号迟早会撞进触发器的建立保持窗口，输出亚稳态。两级同步器让第一级有一整个周期去落定，第二级拍到干净值。亚稳态只能降概率不能消除，指标叫 MTBF，加一级就指数级变长，高速时钟用三级。







  
第 4 章

  
快信号进慢器件：为什么「两级触发器」被判错


  
大白话。第 3 章解决的是「拍到了但拍糊了」。这道题问的是「能不能拍到」。慢器件的快门很久才按一次，快信号一闪而过，完全可能在两次快门之间来了又走。你答两级触发器，相当于在讨论怎么把照片修清晰，可照片根本没拍到。所以面试官说不对。

情况 A · 单个脉冲 / 事件
先「保持住」，再同步

      
FPGA 里用翻转同步：源域每来一个脉冲就翻转一个标志位，慢域同步标志位后做边沿检测还原成脉冲。板级用 D 触发器异步置位把脉冲锁住，慢器件读到后再清零；或者用单稳态 74LVC1G123 把脉冲展宽到器件手册要求的宽度。

    
情况 B · 慢变电平
这才是两级触发器的场景

      
比如一个使能、一个状态标志，几百个慢时钟周期才变一次。每个电平都会覆盖很多个采样沿，直接两级同步就行。

    
情况 C · 多 bit 数据
数据先寄存，使能单独同步

      
源侧把数据寄存住不动，只把一个单 bit 使能用翻转同步传过去，慢侧用同步后的使能采数据。板级对应「锁存器 + 数据就绪标志」。多 bit 不能逐位同步，因为各位延迟不同会拼出乱码。

    
情况 D · 连续数据流
FIFO 吸突发，平均速率必须跟得上

      
用异步 FIFO 或 FIFO 芯片。但 FIFO 只能吸收突发，如果平均速率超过慢侧处理能力，任何手段都救不了，必须抽取、分频、丢弃或反压。

  


  

  

  
为什么面试官说你「时序稳定和静态时序」不牢。「两级触发器」是关键词反射，说明你没分清两层：采得到靠脉宽满足建立保持窗口，这是时序稳定；采错了能落定靠同步器，这是亚稳态处理。静态时序分析只能算有固定相位关系的路径，异步路径它根本不算，所以工具会跳过，这两层只能靠你自己设计保证。第 5 章把这块补上。


  
一句话（面试话术）。先看脉宽能不能覆盖一个慢时钟周期加建立保持，不够就展宽或握手保持住；多 bit 用使能同步或 FIFO；然后再用两级同步器压亚稳态；最后加约束做 CDC 检查。







  
第 5 章

  
静态时序分析 STA：工具到底在算什么


  
大白话。两个触发器之间隔着一段逻辑。上一个触发器拍完，要过 Tcq 才把结果送出来，再走 Tlogic 的路才到下一个触发器门口。下一个触发器的快门在一个周期后按下，门口的信号必须提前 Tsu 到齐（建立检查），而且快门按完 Th 之内不能被下一批数据冲掉（保持检查）。STA 就是对芯片里每一条这样的路做这两道减法，得数叫 slack，负了就是违例。


  

    
动手试：拖一拖，看建立和保持什么时候违例

    

      
      
      
      
      
      
    

    
    

      
建立 slack

      
保持 slack

      
这条路允许的最高频率

    

    

    
建立: Tcq + Tlogic + Tsu ≤ Tclk + Tskew      → 建立 slack = Tclk + Tskew − (Tcq + Tlogic + Tsu)
保持: Tcq + Tlogic ≥ Th + Tskew              → 保持 slack = Tcq + Tlogic − (Th + Tskew)
最高频率 fmax = 1 / (Tcq + Tlogic + Tsu − Tskew)
记法：建立怕「路太长」，保持怕「路太短」；skew 帮建立、害保持。

  


  
STA 和异步信号的关系：这才是那道题的根

  
    
    
  • STA 的前提是发射沿和捕获沿有确定的相位关系，它才能做上面两道减法。
    • 
    
  • 异步信号没有这个关系，STA 算不了任何东西，所以要用 set_false_path 或 set_clock_groups 告诉工具「别算」。
    • 
    
  • 跳过之后功能靠两样东西保证：脉宽判据保证「采得到」，同步器保证「采糊了能落定」。
    • 
    
  • 所以两级触发器是「STA 管不了之后的补救」，不是「保证被采到」的手段。把这两层分开说，面试官就知道你懂了。
    • 
  


  

    
名词一句话

    
Tco / Tcq时钟沿到输出稳定的延迟。

    
恢复 / 移除时间异步复位的「建立 / 保持」：复位释放要在时钟沿前多久、后多久保持不动。所以复位要「异步复位、同步释放」。

    
最小脉宽时钟或复位脉冲不能窄于器件规定，否则触发器不响应。快信号进慢器件也要查这一条。

    
multicycle path告诉工具这条路允许走 N 个周期，别按 1 个周期卡。

    
false path告诉工具这条路不用算，典型就是异步跨时钟域路径。

    
时钟抖动 / 不确定度沿不是准时来的，工具把它当成周期变短来扣。

  


  
一句话。STA 对每条寄存器到寄存器的路径做两道减法：建立看数据来得够不够早，保持看数据走得够不够晚。异步路径没有固定相位，STA 不算，所以要靠脉宽判据加同步器自己保证。







  
第 6 章

  
自测：先自己想，再点开对答案

  
面试官要的顺序永远是「失效机理 → 判据 → 方案」。每道题先在心里按这个顺序说一遍，再点开。


  
一颗 MT41K256M16 的位宽、深度、容量各是多少？地址线几根？
位宽 16，深度 256M = 2^28，容量 4Gb = 512MB。地址线不是 28 根：DDR 地址分时复用，行地址 15 根、列地址 10 根共用 A[14:0]，加 3 根 bank 地址 BA[2:0]。

  
两颗 x16 并排接，总线多宽？容量怎么变？再加一个 rank 呢？
总线 32 位，容量 ×2。加 rank 是再放一组颗粒共用数据线、用另一根片选，位宽不变，容量再 ×2。并排是加宽，rank 是加深。

  
DDR3-1600 x32 峰值带宽多少？为什么 MIG 用户接口是 256 位？
1600 MT/s × 32 bit / 8 = 6.4 GB/s。MIG 用户时钟是 DDR 时钟的 1/4，DDR 双沿传输，所以每个用户周期要吞 2 × 4 = 8 拍数据，8 × 32 = 256 位。

  
什么是亚稳态？能彻底消除吗？
异步信号在触发器建立保持窗口内翻转，输出在 0/1 之间晃一段不确定时间。不能消除，只能用同步器降低概率，指标叫 MTBF，每加一级指数级增长。

  
快时钟域一个单周期脉冲要传到慢时钟域，怎么做？为什么两级触发器不够？
两级触发器只解决亚稳态，不解决漏采。脉冲比慢时钟周期窄，可能一个沿都碰不到。先说判据：脉宽 ≥ 慢周期 + Tsu + Th。再给方案：翻转同步、展宽电平、req/ack 握手。板级用触发器锁存后由慢器件清零。

  
多 bit 数据为什么不能逐位加两级触发器？
各位走线延迟和落定时间不同，同一个采样沿有的位采到新值有的采到旧值，拼出一个从没出现过的值。方案：格雷码（只适用每次变 1 的计数器）、数据保持 + 使能同步、握手、异步 FIFO。

  
异步 FIFO 的空满怎么判？指针为什么多一位？为什么用格雷码？
指针多一位区分「追上了」是空还是满。指针转格雷码后两级同步到对方域，格雷码每次只变一位，采错也只是旧值或新值。读域判空：读格雷码等于同步来的写格雷码。写域判满：最高两位相反、其余相等。同步来的指针旧两拍，所以判断是保守的，只会提前报空报满，不会溢出。

  
建立时间和保持时间违例分别是什么原因？怎么修？
建立违例是路太长或时钟太快：优化逻辑、加流水、降频、改约束（multicycle）。保持违例是路太短或 skew 太大：加缓冲延迟、修时钟树，与频率无关，降频救不了保持。

  
为什么 STA 不分析异步路径？那怎么保证功能？
STA 需要发射沿和捕获沿的固定相位关系，异步时钟没有。用 set_clock_groups 或 set_false_path 让工具跳过，功能靠设计保证：脉宽满足采样判据、同步器压亚稳态、格雷码或握手保证多 bit，再用 report_cdc 做结构检查。

  
复位怎么跨时钟域？
异步复位、同步释放。复位拉低可以立刻生效；释放要经过该时钟域自己的两级同步器，否则各触发器在不同周期出复位，违反恢复移除时间。每个时钟域各一个复位同步器。
