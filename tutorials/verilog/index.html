    怎么上这套课

    每一课的页面结构都一样,按顺序往下走就行:

    1. 讲解 —— 这一课的语法在硬件上到底对应什么,配波形或结构图。
    2. 代码 —— code/lessonNN/ 下真实存在的 .v 文件,页面上的代码和磁盘上的完全一致。
    3. 仿真 —— 一条命令跑起来,以及“你应该看到什么”。看不到就是哪里错了。
    4. 练习 —— 4 道题,答案折叠着。先自己写完再展开,这是唯一一条硬规则。
    只读不写等于没学

    Verilog 的难点不在语法量,在于“这行代码综合出什么电路”。这件事只能靠自己写、跑仿真、看波形对不对,反复几十次形成直觉。所有练习都给了答案,但先写再看和直接看,结果完全不同。

    课程清单

    1. 00环境搭建与第一次仿真装好三样东西,把一个模块从编译一路跑到波形窗口。iverilog · vvp · $dumpfile
    2. 01模块、端口与 Testbench端口方向、位宽、例化,以及一个会自己判对错的 Testbench。module · input/output · $display
    3. 02组合逻辑:wire 与 assign运算符全表、拼接与归约,搭出全加器和优先编码器。assign · {} · ?:
    4. 03时序逻辑:always 与两种赋值触发器是怎么来的,阻塞与非阻塞到底差在哪一根波形上。posedge · 非阻塞 · 复位
    5. 04计数器、分频与流水灯计数器模板、用时钟使能取代分频,以及让仿真跑得动的技巧。计数器 · 时钟使能 · parameter
    6. 05if 与 case:译码与显示优先级还是并行,锁存器是怎么被写出来的,数码管动态扫描。case · default · 锁存器
    7. 06边沿检测与按键消抖打拍取沿、跨时钟同步,把机械抖动挡在逻辑外面。打两拍 · 沿脉冲 · 消抖
    8. 07状态机:三段式写法用序列检测器和交通灯,把三段式 FSM 写成肌肉记忆。FSM · Moore/Mealy · 编码
    9. 08参数化与 generate让一个模块适配任意位宽,批量例化出一整排相同电路。parameter · genvar · $clog2
    10. 09存储器:RAM、ROM 与 FIFO数组怎么被推断成块 RAM,以及同步 FIFO 的空满判断。$readmemh · ram_style · FIFO
    11. 10综合项目:UART 收发器发送、接收、波特率、过采样,最后用回环测试自己验证自己。UART · 过采样 · 自检 TB
    12. 11读懂时序图:SDRAM 初始化加餐。认识手册时序图的每一类标签,写出初始化状态机,用行为模型自检。时序图 · tRP/tRFC · 行为模型

    工程结构

    页面里出现的每一段带文件名的代码,磁盘上都有对应文件。想改就直接改,sim.bat 会重新编译。

    五分钟跑通第一个仿真

    1. 按 第 00 课 装好 Icarus Verilog(自带 iverilog 和 vvp)与 GTKWave,在 PowerShell 里 iverilog -V 能打印版本号即算成功。
    2. 进入代码目录:cd D:\desktop\learn\FPGA\code。
    3. 跑第 01 课的与门仿真:.\sim.bat lesson01 and_gate_tb。
    4. 终端里应该出现 4 行真值表和 [PASS],随后自动弹出 GTKWave 波形窗口。
    5. 跑通了就从 第 00 课 开始按顺序往下走。
    cd D:\desktop\learn\FPGA\code
.\sim.bat lesson01 and_gate_tb
[编译] iverilog -g2012 -s and_gate_tb -o build/and_gate_tb.vvp lesson01/*.v
[运行] vvp build/and_gate_tb.vvp
       a=0 b=0 -> y=0   期望 0   [PASS]
       a=0 b=1 -> y=0   期望 0   [PASS]
       a=1 b=0 -> y=0   期望 0   [PASS]
       a=1 b=1 -> y=1   期望 1   [PASS]
[结果] 4/4 通过,0 处不符
[波形] gtkwave build/and_gate_tb.vcd

    练习台:写完按 F5

    课程页面负责讲,练习台负责练。它是一个桌面小程序,把讲解、编辑器、编译、仿真、报错定位装在一个窗口里 —— 你写代码按 F5,它调用你装好的 iverilog 跑自检 Testbench,编译错误直接标到出问题那一行。

    1. 装一次依赖:python -m pip install PySide6
    2. 双击 bench\start.bat,或者命令行 python bench/app.py
    3. 左边选题 → 中间写代码 → F5 → 右下角看 PASS 还是错误行

    题库 12 道题,和 12 节课一对一,每题都有骨架、自检 Testbench 和参考答案。工具链会自动探测:本机 PATH 里没有 iverilog 就去 WSL 里找,路径转换自动做。细节见 bench/README.md。

    练习台和课程页面的分工

    课程页面里的练习答案是折叠着给你看的,靠自觉;练习台里的答案要按按钮才出来,而且先跑一遍测试再决定要不要看。两者内容互补 —— 页面上四道题偏理解,练习台这一道偏动手写完整模块。

    只有一条命令要记

    .\sim.bat <课程目录> <顶层 Testbench 名> —— 它会编译该目录下所有 .v、指定顶层、运行仿真、把波形丢到 build\ 并打开 GTKWave。后面每一课的仿真步骤都是这一条命令换个参数。
