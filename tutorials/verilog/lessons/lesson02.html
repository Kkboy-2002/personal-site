    Lesson 02 ／ 组合逻辑

    组合逻辑:wire 与 assign

    组合逻辑是没有记忆的电路:输出只由当前输入决定,输入一变输出立刻跟着变。这一课把 assign 和全部运算符过一遍,然后搭出加法器和优先编码器 —— 顺便解决新手最容易中招的位宽陷阱。

    学完这一课你能
    一句话判断某个信号该声明成 wire 还是 reg
    熟练使用拼接 {}、复制 {n{}} 和归约 |a ^a
    解释为什么 assign sum = a + b; 会把进位悄悄丢掉
    写出优先编码器,并说清“优先级链”和“并行选择”在电路上的差别

    本课路线

      wire 还是 reg,只有一条判据

      这是初学阶段最耗时间的疑问,但规则短得离谱:

      唯一判据

      在 always 或 initial 块里被赋值的信号声明成 reg,其余全部是 wire。就这一句,没有例外。

      对照表
      场景类型为什么
      模块的 inputwire由外部驱动,内部只能读
      用 assign 驱动的信号wireassign 只能驱动线网
      子模块的 output 接出来的线wire由那个子模块驱动
      在 always 里赋值的信号reg过程块只能给变量赋值
      Testbench 里的激励信号reg在 initial 里赋值

      reg 这个名字是 Verilog 历史上最坏的一个命名。它不代表寄存器,只代表“过程块里的变量”。真正决定综合出触发器还是组合逻辑的,是这个 always 块怎么写(第 03 课)。SystemVerilog 用 logic 一举取消了这个纠结 —— 如果你的工具支持,可以全用 logic。

      assign:一根永远在算的线

      assign 叫“连续赋值”,意思是右边任何一个信号变化,左边立刻重新计算。它不是“执行一次”,而是一条永远接着的电路。

      同一个 wire 不能被 assign 两次

      写了两条 assign y = …; 就是两个电路同时驱动一根线 —— 综合工具报多驱动错误,仿真里得到 x。想“分情况赋值”,要么合成一条三目运算符,要么改用 always @(*) 配 if/else(第 05 课)。

      运算符全表

      Verilog 运算符
      类别运算符说明综合
      算术+ - *加减乘。乘法会占用 DSP 或大量 LUT可综合
      算术/ % **除、取模、幂。除数不是 2 的幂时代价极大,改用 IP 核慎用
      位运算~ & | ^ ~^逐位操作,输出位宽 = 输入位宽可综合
      逻辑! && ||结果只有 1 位。!a 是“a 是否为 0”,~a 是逐位取反可综合
      关系> < >= <=比较,结果 1 位。注意 <= 在过程块里是非阻塞赋值可综合
      相等== !=任一边含 x/z,结果就是 x可综合
      全等=== !==把 x/z 也当值来比,只有仿真里有意义仅仿真
      归约&a ~&a |a ~|a ^a ~^a把一个向量收成 1 位。^a 就是奇偶校验可综合
      移位<< >>逻辑移位,空位补 0。移固定位数时零成本,只是换根线可综合
      算术移位<<< >>>右移时保留符号位,配合 signed 使用可综合
      拼接{a, b}把多个信号接成更宽的一个可综合
      复制{4{a}}把 a 重复 4 遍可综合
      条件c ? x : y二选一,可以串起来做多选一可综合

      拼接、复制、归约:三个真正的高频动作

      这三个不是语法点缀,是每天都会写的东西。

      移位与拼接的选择

      data >> 1 和 {1'b0, data[7:1]} 综合结果完全一样,都是零成本的换线。但拼接写法能明确表达“空位补什么”,做循环移位({data[0], data[7:1]})时更是只有拼接能写。

      加法器:位宽陷阱就在这里

      一位的加法可以手推真值表。到了 8 位,没人会去串 8 个全加器 —— 直接写 +,综合工具会用芯片里专门的进位链资源实现,比你手搭的快得多。但这里有个坑:

      位宽规则,记这三条就够
      • 表达式按等号两边所有操作数中最宽的那个来计算,包括左边。
      • 裸写的常数(如 1)默认是 32 位,可能悄悄把整个表达式撑到 32 位。写 1'b1 更安全。
      • 宽的赋给窄的会静默截断,不报错、不警告。中间结果宁可多留一位。

      优先编码器:第一次遇到“优先级”

      八个请求同时来了,该响应哪个?优先编码器给出“最高优先级的那个的编号”。

      优先级链 与 并行选择的差别
      三目链 / if…else ifcase / 独立判断
      电路形状一串级联的选择器,有先后一层并列的选择器,没有先后
      逻辑深度随分支数线性增长,路径变长基本恒定
      适合条件会同时成立,需要谁赢谁输条件互斥,比如按 sel 选一路

      这里必须用优先级链 —— 八个请求可以同时为 1,而 idx 只能输出一个数。而第 01 课的 mux4 里 sel 只可能是一个值,条件天然互斥,用 case 更合适(第 05 课)。选错的代价是白白拉长关键路径,在高频设计里会直接卡住时序。

      穷举 vs 随机

      纯组合逻辑输入位数 ≤ 16 时(65536 种),直接双层 for 穷举,几秒就跑完,而且是完备的。位数一多再上随机 + 边界值。这门课后面凡是能穷举的地方都穷举。

      练习

      1. 一行搞定奇偶校验热身

        写 code/lesson02/parity.v:输入 8 位 data,输出 even_p(偶校验位)和 odd_p(奇校验位)。每个输出只准写一行。

        参考答案
        module parity (
    input  wire [7:0] data,
    output wire       even_p,   // 补上它之后,1 的总数是偶数
    output wire       odd_p     // 补上它之后,1 的总数是奇数
);
    assign even_p = ^data;      // data 里有奇数个 1 时输出 1,正好凑成偶数
    assign odd_p  = ~^data;     // 取反即可
endmodule

        归约异或就是奇偶校验的全部内容。UART 的校验位、以太网的 FCS、内存的 ECC,底层都是这一个运算符往上堆。

      2. 8 位比较器动手

        写 cmp8.v:输入 a、b,输出 gt、eq、lt 三个 1 位信号。写完想一想:如果 a = 8'hFF、b = 8'h01,你的电路说谁大?如果这两个数其实代表有符号数呢?

        参考答案
        module cmp8 (
    input  wire [7:0] a,
    input  wire [7:0] b,
    output wire       gt,
    output wire       eq,
    output wire       lt
);
    assign gt = (a >  b);
    assign eq = (a == b);
    assign lt = (a <  b);
endmodule

        默认无符号:8'hFF 是 255,比 1 大。若这两个数是有符号的,8'hFF 就是 −1,结果完全相反。

        改成有符号只需在声明上加 signed:input wire signed [7:0] a, b;,或者在表达式里临时转换 $signed(a) > $signed(b)。同一串比特,解释方式不同结论就不同 —— 这是位宽之外第二个高发 bug 来源。

      3. 桶形移位器动手

        写 barrel_shift8.v:输入 8 位 din、3 位移位量 shamt、1 位模式 rotate(0 = 逻辑左移,1 = 循环左移),输出 dout。不准用 always,只用 assign。提示:把 din 拼成 16 位,然后开个 8 位的窗口去取。

        参考答案
        module barrel_shift8 (
    input  wire [7:0] din,
    input  wire [2:0] shamt,
    input  wire       rotate,      // 0=逻辑左移  1=循环左移
    output wire [7:0] dout
);
    wire [15:0] pad = {din, 8'b0}; // 逻辑移位:低位补零
    wire [15:0] dbl = {din, din};  // 循环移位:接一份自己
    wire [15:0] src = rotate ? dbl : pad;

    // 索引部分选择:从第 (15-shamt) 位开始,往低位数 8 位
    assign dout = src[15-shamt -: 8];
endmodule

        验一下 shamt=1:pad[14:7] = {din[6:0], 1'b0} 正是左移一位;dbl[14:7] = {din[6:0], din[7]} 正是循环左移一位。同一个窗口表达式,换个源就换了功能 —— 这就是把移位问题“摊平成选线问题”的技巧。

      4. 故意制造一次多驱动想清楚

        在 adder8.v 里多加一行 assign cout = 1'b0;,重跑 comb_tb。cout 变成了什么?为什么综合工具会把这件事当成错误而不是警告?

        参考答案

        仿真里 cout 会变成 x。线网的规则是:两个驱动源给出不同的值,结果就是不确定 —— 这正是真实电路的行为(两个输出短接在一起,电压既不是高也不是低)。两个驱动恰好给出相同值时反而不报错,这让 bug 更难查。

        综合工具直接报错(Vivado 的 multiple driver nets),因为它没法为这种网络生成电路。真实芯片上把两个驱动器短接会持续灌电流,可能烧掉引脚。

        推论:一个信号,一个驱动源。要分情况赋值,就把所有情况收进同一条 assign(用三目链)或同一个 always 块。
