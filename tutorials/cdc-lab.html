CDC 跨时钟域实验台

一根信号从时钟 A 的寄存器，走到时钟 B 的寄存器。两个时钟没有固定关系，这一步就叫跨时钟域。下面 4 个实验，每个只讲一件事：先看它怎么坏，再看怎么修。拖动滑块，盯着寄存器里的数字和右边的波形。

1亚稳态 2两级同步器 3脉冲丢失 4多比特撕裂 5约束与选型
实验 1

亚稳态：数据变化撞上时钟沿

寄存器在时钟上升沿采样 D。沿前 1 ns、沿后 0.5 ns 这一小段叫建立/保持窗口，D 不许在这里面变。变了，Q 就会卡在 0 和 1 之间一段时间，这就是亚稳态，记作 X。

沿前 4 ns红色窗口沿后 4 ns
看看有多少次会撞进窗口

  • 窗口外变化：完全没事。要么这个沿采到，要么下一个沿采到，最多晚一拍。
  • 窗口内变化：Q 变成 X。多久稳定、最后稳到 0 还是 1，都不可控。下游此时读到的就是垃圾。
  • 真芯片的窗口只有几十皮秒，这里放大到 1.5 ns 是为了看得见。但时钟一秒跑一亿次，天天撞。所以要靠结构来防，不能靠运气。
实验 2

两级同步器：让 X 死在第一级

在 B 域再加一个寄存器 FF2，它在下一个沿才去采 Q1。这时 Q1 的 X 大概率已经稳定成 0 或 1 了。下游只看 Q2，永远看不到 X。

沿前 4 ns红色窗口沿后 4 ns

  • 第二级不是魔法：它只是隔了一整个周期再采样，把 X 的恢复时间留足。X 拖得越久，越过下一个沿的概率越小，这个概率算出来就是 MTBF。
  • 代价：晚 1 到 2 拍。而且只适合电平信号，也就是变化慢、能保持好几拍的信号。一拍宽的脉冲不行，见实验 3。
  • 写法：两级都加 ASYNC_REG 属性，工具会把它们放在相邻位置，中间不插任何逻辑。
Verilog：两级同步器 
// 单比特电平信号：两级同步器
(* ASYNC_REG = "TRUE" *) reg q1, q2;   // 告诉工具：这两级要挨着放
always @(posedge clk_b) begin
  q1 <= d_from_a;   // 第一级可能进入亚稳态
  q2 <= q1;         // 第二级在下一拍采样，X 已经稳定
end
// 下游只能用 q2，绝不能用 q1
实验 3

脉冲丢失：快时钟发一拍，慢时钟没看见

A 是 250 MHz，周期 4 ns。B 是 100 MHz，每 10 ns 才采样一次。A 发一个只有一拍宽的脉冲，B 的两个沿之间完全可能一个都没赶上。这个实验先不管亚稳态，同步器按实验 2 处理。

方案一直接用 B 的寄存器采

方案二翻转同步器：脉冲先变成电平

  • 思路：脉冲会丢，电平不会丢。A 域每来一个脉冲，就把 T 翻转一次。T 是电平，用实验 2 的两级同步器送过去。
  • 还原：B 域再存一拍得到 s3。s2 和 s3 不同的那一拍，就说明 T 刚翻过，输出一个 B 域宽度的脉冲。
  • 限制：两个脉冲之间至少隔 2 到 3 个 B 周期。勾上「连发第二个脉冲」就能看到，T 翻上去又翻下来，B 可能一次都没看见。
Verilog：翻转同步器 
// A 域：把脉冲变成翻转电平
reg t_a;
always @(posedge clk_a) if (pulse_a) t_a <= ~t_a;

// B 域：同步电平，再用异或还原成脉冲
(* ASYNC_REG = "TRUE" *) reg s1, s2;
reg s3;
always @(posedge clk_b) begin
  s1 <= t_a;  s2 <= s1;  s3 <= s2;
end
assign pulse_b = s2 ^ s3;   // s2 和 s3 不同 = 刚翻转过 = 来了一个脉冲
// 限制：两个脉冲至少隔开 2~3 个 clk_b 周期
实验 4

多比特撕裂：三根线到得不一样早

A 域一个 3 位计数器从 3 变到 4，三根线的走线长度不同，到 B 的时间差了好几纳秒。B 在中间某一刻采样，就会采到一半新值一半旧值，拼出一个 A 从来没输出过的数。

  • 二进制：3 是 011，4 是 100，三位全变。采样时刻不同，能拼出 0、2、7 这些根本不存在的中间值。这就是撕裂。
  • 格雷码：相邻数值只差一位。3 是 010，4 是 110，只有最高位在变。不管什么时候采，结果只能是旧值或新值，都是真的。
  • 两级同步器为什么不能直接同步总线：它只解决单根线的 X，解决不了几根线到达时间不同的问题。这是面试最常见的追问。
  • 适用范围：格雷码只保护每次加减 1 的计数器和 FIFO 指针。任意跳变的多比特数据，要用握手或者异步 FIFO，见下一节。
Verilog：格雷码转换 
// 二进制 → 格雷码：相邻数值只差一位
assign gray = bin ^ (bin >> 1);

// 格雷码 → 二进制（3 位展开写法，从高位往下异或）
assign bin[2] = gray[2];
assign bin[1] = gray[2] ^ gray[1];
assign bin[0] = gray[2] ^ gray[1] ^ gray[0];

// 用法：A 域计数器转格雷码 → 每一位各走一个两级同步器 → B 域转回二进制
第 5 节

把它们连起来：选型、约束、检查

前四个实验就是 CDC 的全部底层原理。工程上只剩三件事：按信号类型选方法，把跨域路径告诉工具，最后跑一次检查。

要跨过去的信号用什么代价
单比特、变化慢的电平，比如使能、状态标志两级同步器晚 1 到 2 拍
单比特脉冲翻转同步器，或 req/ack 握手脉冲之间要留间隔
计数器、FIFO 读写指针格雷码，每位各走两级同步器每次只能加减 1
任意跳变的多比特数据异步 FIFO，或握手加数据保持面积、延迟
复位异步复位、同步释放几乎没有
XDC 约束与检查（Vivado） 
# 1. 同步器两级放在一起，不插逻辑
set_property ASYNC_REG TRUE [get_cells {u_sync/q1_reg u_sync/q2_reg}]

# 2. 跨域路径不按普通时序分析，但限制走线延迟不超过一个目的时钟周期
set_max_delay -datapath_only -from [get_clocks clk_a] -to [get_clocks clk_b] 10.0

# 3. 把所有没做同步器的跨域路径列出来
report_cdc

面试常见追问

两级同步器为什么不能直接同步多比特总线？
各位到达时间不同，撞窗口的可能是任意一位。两级只解决每根线自己的 X，解决不了几根线拼出幻影值，见实验 4。
两级够不够，什么时候要三级？
看 MTBF。频率越高、周期越短，留给 X 恢复的时间越少。几百 MHz 以上或者可靠性要求高的地方，加到三级。
快时钟到慢时钟的脉冲怎么办？
翻转同步器或握手，见实验 3。或者在 A 域先把脉冲拉宽到至少覆盖 1.5 个 B 周期，再按电平同步。
set_false_path 和 set_max_delay -datapath_only 有什么区别？
前者完全不管这条路径，走线再长也不报。后者不做建立保持分析，但限制数据路径延迟，防止走线过长把总线撕得更开。跨域路径优先用后者。
仿真里的时序参数都为了看得清而放大：建立 1 ns、保持 0.5 ns、寄存器延迟 0.7 ns、走线偏差最多 4.2 ns。真实 FPGA 的数字小一到两个量级，但道理一样。
